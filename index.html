About Progains

Progains is a strength-training and workout tracking app for iPhone. It's built for people who train with weights and want their plan, their sessions, and their progress in one place.

  • Programs — multi-week plans with phases, training days and rest days, laid out on a schedule
  • Templates — single reusable workouts you can start any time
  • Exercise library — a starting set you can edit, plus your own exercises with notes, cues and photos
  • Workout logging — reps, weight and RPE for every set, with warm-up, working and drop sets, and automatic rest timers
  • History — every finished workout saved, searchable and browsable on a calendar
  • Progress — estimated 1-rep max charted over time, with Premium
  • Cloud Sync — your training on all your devices through your own iCloud, with Premium

Recording workouts always works offline. Progains saves your training to your device as you go. An internet connection is only needed to buy a subscription and, if you're a Premium subscriber with Cloud Sync on, to sync to iCloud.

Programs

A program is a repeating training plan that Progains lays out on a schedule for you to follow day by day. Build one in the Planner tab, under Programs.

Building a program

  1. Give the program a name, and optional notes.
  2. Choose how long it runs: Fixed Weeks for a plan with an end date, or Forever for one that keeps repeating.
  3. Add phases if you want them. A phase is a multi-week block with its own name and week count — useful for splitting a plan into stages such as hypertrophy, then strength, then a peak. If you'd rather keep things simple, a program can run as a single block instead.
  4. Inside a phase, add the days that repeat. Each day has a label and its own list of exercises, with the sets and reps you intend to hit.
  5. Mark any day as a rest day. Rest days are part of the pattern, so a 3-on-1-off week is just four days with the fourth marked as rest.

Running a program

Set a program as active and Progains builds your schedule from it. The Start tab then shows the workout that's due, and the calendar shows the days ahead. Only one program is active at a time.

You can pause an active program if you need to step away from training, and pick it up later without losing your place. Which program is active, and whether it's paused, syncs across your devices when Cloud Sync is on.

Free accounts can keep 2 programs. Premium removes the limit. Programs beyond the limit are never deleted — you just can't add new ones until you remove one or upgrade.

Templates

A template is a single reusable workout — no schedule, no weeks, just a session you repeat. Use templates when you train by feel but still want the same session set up and ready.

Create them in the Planner tab under Templates: name the workout, add exercises, and set the sets and reps you plan to do.

Starting a workout from a template

  1. Open the Start tab.
  2. Switch the selector at the top from Program to Template.
  3. Choose one of your saved templates, and the session opens with those exercises already loaded.

The same screen has Start Empty Workout, which begins a session with nothing in it so you can add exercises as you go. Nothing has to be planned in advance.

Free accounts can keep 3 templates. Premium removes the limit.

Exercise library

The Exercises tab is your library. Progains ships with a starting set organized by muscle group and equipment, and you can add your own.

What an exercise holds

  • Name
  • Muscle group — chest, back, shoulders, forearm, biceps, triceps, legs, abdominals, full body, or cardio
  • Equipment — barbell, dumbbell, machine, cable, bodyweight, kettlebell, or band
  • Notes — anything you want to remember about it
  • Instructions — your own form cues, written by you
  • An optional photo — a setup shot, a machine, a plate configuration

Browse by muscle group or search by name. Tap any exercise to edit it, including the ones Progains provided — rename them, add your own cues, or change the equipment to match your gym.

You can delete built-in exercises you don't use. That deletion is remembered, so it won't reappear on your other devices when Cloud Sync is on.

Adding a photo uses the standard iOS photo picker: you choose one image and only that image is handed to the app. Progains never gets access to your photo library.

Logging a workout

Start a workout from the Start tab — either the day your active program has scheduled, or a freestyle session. The logger then stays with you for the whole session.

Recording sets

For every set you record reps, weight, and optionally RPE (rate of perceived exertion) plus a note. Tap the circle to mark a set complete.

Sets come in three kinds, each grouped separately in the exercise:

  • Warm-up sets — add as many as you need before the real work
  • Working sets — the sets that count toward your volume and estimated 1-rep max
  • Drop sets — a working set followed by its drops, recorded together

What you did last time

Each set row shows your previous performance for that exercise, so the number you're trying to beat is always next to the number you're entering.

Rest timers

Rest timers start on their own. There are two, and they do different jobs:

  • Between sets — runs while more sets of the current exercise remain
  • Between exercises — runs after an exercise's last set when another exercise is still to come, and never after the final set of the workout

Set the defaults in Planner › gear icon › Settings, and override the between-sets rest on individual exercises. A timer can be skipped or edited while it runs.

If you leave the app, Progains schedules a notification so you still know when rest is up. If you stay in the app, you get an alert on screen instead.

Pausing and stepping away

You can pause a workout, and paused time is excluded from the recorded duration. Swiping the session down keeps it running as a bar above the tab bar with a live stopwatch — tap it to come back.

Workout logs and history

Finishing a workout saves it: every set, the total volume, the duration, your notes, and how hard the session felt. Nothing is discarded.

Find your workouts in the Logs tab, grouped by month or browsed on a calendar. Search by workout or exercise name. Tap any workout to see it in full, and edit it if you recorded something wrong — editing a finished workout never changes its recorded duration.

How far back you can see

Free: the most recent 3 months of workouts.
Premium: every workout you have ever logged.

This is the one thing worth being precise about: workouts older than three months are not deleted on a free account. They are saved on your device exactly as they were, and they reappear the moment you subscribe. If a subscription lapses, the list simply narrows again — nothing is lost.

Premium

Progains is free to use for the part that matters most: building programs and templates, and logging unlimited workouts. Premium is an optional subscription that adds the following.

  • Cloud Sync — keep workouts, programs, templates and exercises in sync across your devices through your own private iCloud account
  • Full workout history — browse and search every workout you have logged, not just the last three months
  • Progress analytics — your estimated 1-rep max charted over time for every exercise
  • Long-term statistics — trend velocity, plateau detection, and 4-, 8- and 12-week strength projections
  • Unlimited programs — beyond the free limit of 2
  • Unlimited templates — beyond the free limit of 3

Premium is an auto-renewing subscription, offered monthly or annually. The exact price in your currency is shown on the Premium screen in the app, since it is set per App Store region. It renews automatically until you cancel.

Losing Premium never removes your data. Progress charts and older history become unavailable to view and Cloud Sync stops mirroring new changes, but every workout stays on your device and returns if you subscribe again.

Cloud Sync

Cloud Sync is a Premium feature. It keeps your workouts, programs, templates, exercises, and settings consistent across the Apple devices signed in to your Apple Account.

How it works

  • Your workout data is stored on your device first. That local copy is always the one you're using, whether Cloud Sync is on or off.
  • Premium subscribers can turn Cloud Sync on in Progains under Planner › gear icon › Settings › iCloud › Cloud Sync. The change takes effect immediately — no restart required.
  • When it's on, Progains uses Apple's iCloud and CloudKit infrastructure to mirror your data to the private database in your own iCloud account.
  • Because it's your private database, the data moves between your own devices under your Apple Account. The developer of Progains cannot read it and has no access to it.
  • Cloud Sync requires an iPhone signed in to iCloud with a working iCloud account. If you aren't signed in, Progains will say so and keep saving your data locally.
  • Turning Cloud Sync off does not delete anything. It stops mirroring; your local data stays exactly where it is.

Checking your sync status

Open Planner › gear icon › Settings. When Cloud Sync is on, a Status section appears showing the current state — Syncing…, Synced, Not signed in to iCloud, Sync error, or Local only — along with a This device row and the time of the last successful sync.

"Local only" status

In Settings › Status, the This device row shows either iCloud active or Local only.

Local only means exactly what it says: your workout data is saved safely on this iPhone, but iCloud mirroring did not start on this device, so recent changes have not been copied up to iCloud. Nothing has been lost — the data is intact locally.

This can happen if the local database needs to migrate to a sync-compatible format, or if iCloud isn't fully set up on the device.

Troubleshooting steps

  1. Check your internet connection. Confirm Wi-Fi or cellular data is working on the device.
  2. Check that you're signed in to iCloud. Open Settings › [your name] on your iPhone and make sure you're signed in and that iCloud is enabled.
  3. Check that Cloud Sync is on in Progains. Open Planner › gear icon › Settings › iCloud and confirm the Cloud Sync toggle is on. The toggle only appears while your Premium subscription is active.
  4. Check that your Premium subscription is active. If it has lapsed, the Status section will say Premium required. See Manage or cancel a subscription.
  5. Check your iCloud account and storage. Open Settings › [your name] › iCloud and confirm the account is healthy and you haven't run out of iCloud storage.
  6. Quit and reopen Progains, then give it time. Fully close the app and open it again, then leave it open for a minute or two on a good connection. Syncing runs in the background and isn't always instant.
  7. Still stuck? The Status section shows a technical detail line under the Local only and Sync error states, and the error state includes a Copy Error Details button. Copy that text and send it to support — it tells us exactly what went wrong.

Your data is safe either way. Progains always writes your workouts to the device first. A sync problem affects whether changes reach your other devices, not whether your training is recorded.

Restore purchases

If you've already subscribed to Progains Premium — for example on another device, or before reinstalling the app — you can restore your subscription without paying again.

  1. Open Progains on your iPhone.
  2. Open the Premium screen. You can reach it from any Premium prompt in the app — the quickest route is the Planner tab, then the gear icon in the top-left corner to open Settings, then Unlock Premium in the iCloud section. The Progress tab and the locked history card at the bottom of the Logs tab open the same screen.
  3. On the Progains Premium screen, tap Restore Purchases (below the subscribe button).
  4. Wait a moment while the App Store checks your account. Once your subscription is found, Premium features unlock immediately — no restart needed.

Make sure the device is signed in to the Apple Account that originally bought the subscription. Restoring reads your purchase history from Apple, so a different Apple Account will not find it. You can check which account is signed in under Settings › [your name] › Media & Purchases on your iPhone.

If the Premium screen already says "You're Premium", your subscription is active and there is nothing to restore.

Subscription purchases are handled entirely by Apple through the App Store. Progains never sees or processes your payment information — the app only receives whether your subscription is currently active.

Manage or cancel a subscription

Progains Premium is an auto-renewing subscription sold through the App Store, so it is managed in your Apple Account rather than inside the app. Pricing, renewal date, plan changes, and cancellation are all handled there.

Manage or Cancel Subscription

https://apps.apple.com/account/subscriptions

You can also get there on your iPhone: open Settings, tap your name at the top, tap Subscriptions, then select Progains.

What happens to my data if I cancel?

Cancelling does not erase your workout data. Everything you've recorded stays saved on your device exactly as it was, and you can keep using Progains to create exercises, run workouts, and log your training.

What changes is access to Premium features. When the subscription lapses, Progains stops mirroring new changes to iCloud and the workout history list returns to the most recent three months. Your older workouts are not deleted — they're still stored on your device, and they reappear if you subscribe again.

Refunds are handled by Apple, not by Progains. Requests can be made at reportaproblem.apple.com.

How workout data is stored

Progains stores your workout information — your exercises, programs, templates, scheduled days, workouts, and every set, rep, weight, and RPE you log — on your iPhone, in the app's own local database.

If you're a Premium subscriber and you turn Cloud Sync on, that same data is also mirrored to the private CloudKit database in your own iCloud account, which is what lets it appear on your other Apple devices.

Progains does not run its own server for your workout data. There is no Progains account to create, no login, and no Progains backend that your training is uploaded to. Your data is either on your device or in your own iCloud — never on a server run by the developer, and never sent to a third party.

For the full detail on what is stored and where, see the Progains Privacy Policy.

Über Progains

Progains ist eine iPhone-App für Krafttraining und Trainingsaufzeichnung. Sie ist für alle gemacht, die mit Gewichten trainieren und ihren Plan, ihre Einheiten und ihren Fortschritt an einem Ort haben wollen.

  • Programme — mehrwöchige Pläne mit Phasen, Trainings- und Ruhetagen, fertig als Zeitplan angelegt
  • Vorlagen — einzelne, wiederverwendbare Trainings, die du jederzeit starten kannst
  • Übungsbibliothek — eine Grundauswahl, die du bearbeiten kannst, plus deine eigenen Übungen mit Notizen, Hinweisen und Fotos
  • Training aufzeichnen — Wiederholungen, Gewicht und RPE für jeden Satz, mit Aufwärm-, Arbeits- und Dropsätzen sowie automatischen Pausentimern
  • Verlauf — jedes abgeschlossene Training gespeichert, durchsuchbar und im Kalender abrufbar
  • Fortschritt — dein geschätztes Einwiederholungsmaximum (1RM) im Zeitverlauf als Diagramm, mit Premium
  • Cloud-Sync — dein Training auf allen deinen Geräten über deine eigene iCloud, mit Premium

Trainings aufzeichnen funktioniert immer offline. Progains speichert dein Training währenddessen direkt auf deinem Gerät. Eine Internetverbindung brauchst du nur, um ein Abo zu kaufen und, wenn du Premium hast und Cloud-Sync eingeschaltet ist, um mit iCloud zu synchronisieren.

Programme

Ein Programm ist ein wiederkehrender Trainingsplan, den Progains als Zeitplan für dich anlegt, damit du ihm Tag für Tag folgen kannst. Erstelle eins im Tab Planer unter Programme.

Ein Programm erstellen

  1. Gib dem Programm einen Namen und optional Notizen.
  2. Lege fest, wie lange es läuft: Feste Wochen für einen Plan mit Enddatum oder Unbegrenzt für einen, der sich immer weiter wiederholt.
  3. Füge Phasen hinzu, wenn du magst. Eine Phase ist ein mehrwöchiger Block mit eigenem Namen und eigener Wochenzahl — praktisch, um einen Plan in Abschnitte zu teilen, etwa Hypertrophie, dann Kraft, dann Peaking. Wenn du es lieber einfach hältst, läuft ein Programm auch als ein einziger Block.
  4. Füge innerhalb einer Phase die Tage hinzu, die sich wiederholen. Jeder Tag hat eine Bezeichnung und eine eigene Übungsliste mit den Sätzen und Wiederholungen, die du schaffen willst.
  5. Markiere jeden beliebigen Tag als Ruhetag. Ruhetage gehören zum Muster: Eine Woche mit 3 Trainingstagen und 1 freien Tag sind einfach vier Tage, bei denen der vierte als Ruhetag markiert ist.

Ein Programm durchziehen

Setze ein Programm auf aktiv, und Progains baut daraus deinen Zeitplan. Der Tab Start zeigt dann das Training, das ansteht, und der Kalender die kommenden Tage. Es ist immer nur ein Programm aktiv.

Du kannst ein aktives Programm pausieren, wenn du eine Trainingspause brauchst, und später weitermachen, ohne deinen Platz zu verlieren. Welches Programm aktiv ist und ob es pausiert ist, wird auf deinen Geräten synchronisiert, wenn Cloud-Sync eingeschaltet ist.

Mit einem kostenlosen Account kannst du 2 Programme behalten. Premium hebt das Limit auf. Programme über dem Limit werden nie gelöscht — du kannst nur keine neuen anlegen, bis du eins entfernst oder auf Premium wechselst.

Vorlagen

Eine Vorlage ist ein einzelnes, wiederverwendbares Training — kein Zeitplan, keine Wochen, einfach eine Einheit, die du wiederholst. Vorlagen sind ideal, wenn du nach Gefühl trainierst, dieselbe Einheit aber trotzdem fertig vorbereitet haben willst.

Erstelle sie im Tab Planer unter Vorlagen: Training benennen, Übungen hinzufügen und die Sätze und Wiederholungen festlegen, die du machen willst.

Ein Training aus einer Vorlage starten

  1. Öffne den Tab Start.
  2. Stelle die Auswahl oben von Programm auf Vorlage um.
  3. Wähle eine deiner gespeicherten Vorlagen aus, und die Einheit öffnet sich mit den darin enthaltenen Übungen.

Auf demselben Bildschirm findest du Leeres Training starten. Damit beginnst du eine Einheit ohne Inhalt und fügst Übungen hinzu, während du trainierst. Nichts muss vorher geplant sein.

Mit einem kostenlosen Account kannst du 3 Vorlagen behalten. Premium hebt das Limit auf.

Übungsbibliothek

Der Tab Übungen ist deine Bibliothek. Progains bringt eine Grundauswahl mit, sortiert nach Muskelgruppe und Equipment, und du kannst eigene Übungen ergänzen.

Was zu einer Übung gehört

  • Name
  • Muskelgruppe — Brust, Rücken, Schultern, Unterarm, Bizeps, Trizeps, Beine, Bauch, Ganzkörper oder Cardio
  • Equipment — Langhantel, Kurzhantel, Maschine, Kabelzug, Körpergewicht, Kettlebell oder Band
  • Notizen — alles, was du dir dazu merken willst
  • Anleitung — deine eigenen Technikhinweise, von dir geschrieben
  • Ein optionales Foto — dein Setup, die Maschine, die Scheibenbelegung

Stöbere nach Muskelgruppe oder suche nach dem Namen. Tippe auf eine beliebige Übung, um sie zu bearbeiten, auch auf die von Progains mitgelieferten — benenne sie um, ergänze eigene Hinweise oder ändere das Equipment passend zu deinem Gym.

Mitgelieferte Übungen, die du nicht brauchst, kannst du löschen. Das Löschen wird gemerkt, damit die Übung auf deinen anderen Geräten nicht wieder auftaucht, wenn Cloud-Sync eingeschaltet ist.

Für ein Foto nutzt Progains die Standard-Fotoauswahl von iOS: Du wählst ein Bild aus, und nur dieses Bild wird an die App übergeben. Progains erhält nie Zugriff auf deine Fotomediathek.

Ein Training aufzeichnen

Starte ein Training im Tab Start — entweder den Tag, den dein aktives Programm vorsieht, oder eine freie Einheit. Die Aufzeichnung begleitet dich dann durch die gesamte Einheit.

Sätze aufzeichnen

Für jeden Satz erfasst du Wiederholungen, Gewicht und optional RPE (empfundene Anstrengung) sowie eine Notiz. Tippe auf den Kreis, um einen Satz als erledigt zu markieren.

Es gibt drei Arten von Sätzen, die in der Übung jeweils getrennt gruppiert werden:

  • Aufwärmsätze — füge so viele hinzu, wie du vor der eigentlichen Arbeit brauchst
  • Arbeitssätze — die Sätze, die in dein Volumen und dein geschätztes 1RM einfließen
  • Dropsätze — ein Arbeitssatz und die anschließenden Drops, zusammen aufgezeichnet

Was du letztes Mal geschafft hast

Jede Satzzeile zeigt deine letzte Leistung bei dieser Übung. So steht die Zahl, die du schlagen willst, immer direkt neben der Zahl, die du gerade eingibst.

Pausentimer

Pausentimer starten von selbst. Es gibt zwei, und sie haben unterschiedliche Aufgaben:

  • Zwischen Sätzen — läuft, solange noch weitere Sätze der aktuellen Übung offen sind
  • Zwischen Übungen — läuft nach dem letzten Satz einer Übung, wenn noch eine weitere Übung folgt, und nie nach dem letzten Satz des Trainings

Die Standardwerte legst du unter Planer › Zahnrad-Symbol › Einstellungen fest, und die Pause zwischen Sätzen kannst du bei einzelnen Übungen abweichend einstellen. Einen laufenden Timer kannst du überspringen oder anpassen.

Wenn du die App verlässt, plant Progains eine Mitteilung, damit du trotzdem mitbekommst, wann die Pause vorbei ist. Bleibst du in der App, bekommst du stattdessen einen Hinweis auf dem Bildschirm.

Pausieren und kurz weggehen

Du kannst ein Training pausieren; die pausierte Zeit zählt nicht zur aufgezeichneten Dauer. Wenn du die Einheit nach unten wischst, läuft sie als Leiste über der Tab-Leiste weiter, mit laufender Stoppuhr — tippe darauf, um zurückzukehren.

Trainingsaufzeichnungen und Verlauf

Wenn du ein Training beendest, wird es gespeichert: jeder Satz, das Gesamtvolumen, die Dauer, deine Notizen und wie anstrengend sich die Einheit angefühlt hat. Nichts wird verworfen.

Deine Trainings findest du im Tab Verlauf, nach Monat gruppiert oder im Kalender. Suche nach Trainings- oder Übungsnamen. Tippe auf ein Training, um es vollständig zu sehen, und bearbeite es, falls du etwas falsch erfasst hast — das Bearbeiten eines abgeschlossenen Trainings ändert nie seine aufgezeichnete Dauer.

Wie weit du zurückblicken kannst

Kostenlos: die Trainings der letzten 3 Monate.
Premium: jedes Training, das du je aufgezeichnet hast.

Hier lohnt es sich, genau zu sein: Trainings, die älter als drei Monate sind, werden mit einem kostenlosen Account nicht gelöscht. Sie bleiben genau so auf deinem Gerät gespeichert, wie sie waren, und sind sofort wieder da, sobald du ein Abo abschließt. Läuft ein Abo aus, wird die Liste einfach wieder kürzer — verloren geht nichts.

Premium

Progains ist genau da kostenlos, wo es am meisten zählt: Programme und Vorlagen erstellen und unbegrenzt Trainings aufzeichnen. Premium ist ein optionales Abo, das Folgendes ergänzt.

  • Cloud-Sync — Trainings, Programme, Vorlagen und Übungen über deinen eigenen, privaten iCloud-Account auf allen Geräten synchron halten
  • Vollständiger Trainingsverlauf — jedes aufgezeichnete Training ansehen und durchsuchen, nicht nur die letzten drei Monate
  • Fortschrittsanalysen — dein geschätztes 1RM im Zeitverlauf als Diagramm, für jede Übung
  • Langzeitstatistiken — Trendgeschwindigkeit, Plateau-Erkennung und Kraftprognosen für 4, 8 und 12 Wochen
  • Unbegrenzt viele Programme — über das kostenlose Limit von 2 hinaus
  • Unbegrenzt viele Vorlagen — über das kostenlose Limit von 3 hinaus

Premium ist ein Abo mit automatischer Verlängerung, wahlweise monatlich oder jährlich. Den genauen Preis in deiner Währung siehst du im Premium-Bereich der App, denn er wird pro App-Store-Region festgelegt. Das Abo verlängert sich automatisch, bis du kündigst.

Wenn Premium endet, werden deine Daten nie entfernt. Fortschrittsdiagramme und der ältere Verlauf lassen sich dann nicht mehr ansehen, und Cloud-Sync überträgt keine neuen Änderungen mehr. Aber jedes Training bleibt auf deinem Gerät und ist wieder da, sobald du erneut abonnierst.

Cloud-Sync

Cloud-Sync ist eine Premium-Funktion. Sie hält deine Workouts, Programme, Vorlagen, Übungen und Einstellungen auf allen Apple-Geräten konsistent, die bei deinem Apple-Account angemeldet sind.

So funktioniert es

  • Deine Trainingsdaten werden zuerst auf deinem Gerät gespeichert. Diese lokale Kopie ist immer die, mit der du arbeitest – egal ob Cloud-Sync an oder aus ist.
  • Mit einem Premium-Abo kannst du Cloud-Sync in Progains unter Planer › Zahnrad-Symbol › Einstellungen › iCloud › Cloud-Sync einschalten. Die Änderung wirkt sofort – ein Neustart ist nicht nötig.
  • Wenn Cloud-Sync an ist, nutzt Progains die iCloud- und CloudKit-Infrastruktur von Apple, um deine Daten in die private Datenbank deines eigenen iCloud-Accounts zu spiegeln.
  • Weil es deine private Datenbank ist, bewegen sich die Daten zwischen deinen eigenen Geräten unter deinem Apple-Account. Der Entwickler von Progains kann sie nicht lesen und hat keinen Zugriff darauf.
  • Cloud-Sync setzt ein iPhone voraus, das mit einem funktionierenden iCloud-Account bei iCloud angemeldet ist. Bist du nicht angemeldet, weist dich Progains darauf hin und speichert deine Daten weiterhin lokal.
  • Cloud-Sync auszuschalten löscht nichts. Es beendet nur das Spiegeln; deine lokalen Daten bleiben genau dort, wo sie sind.

Sync-Status prüfen

Öffne Planer › Zahnrad-Symbol › Einstellungen. Wenn Cloud-Sync an ist, erscheint ein Bereich Status mit dem aktuellen Zustand – Wird synchronisiert …, Synchronisiert, Nicht bei iCloud angemeldet, Sync-Fehler oder Nur lokal – zusammen mit der Zeile Dieses Gerät und dem Zeitpunkt der letzten erfolgreichen Synchronisierung.

Der Status „Nur lokal“

Unter Einstellungen › Status zeigt die Zeile Dieses Gerät entweder iCloud aktiv oder Nur lokal an.

Nur lokal heißt genau das: Deine Trainingsdaten sind sicher auf diesem iPhone gespeichert, aber die Spiegelung nach iCloud ist auf diesem Gerät nicht gestartet – die letzten Änderungen wurden also nicht zu iCloud übertragen. Verloren gegangen ist nichts, die Daten sind lokal vollständig vorhanden.

Das kann passieren, wenn die lokale Datenbank erst in ein sync-fähiges Format überführt werden muss oder wenn iCloud auf dem Gerät nicht vollständig eingerichtet ist.

Schritte zur Fehlerbehebung

  1. Prüfe deine Internetverbindung. Vergewissere dich, dass WLAN oder Mobilfunk auf dem Gerät funktioniert.
  2. Prüfe, ob du bei iCloud angemeldet bist. Öffne auf deinem iPhone Einstellungen › [dein Name] und stelle sicher, dass du angemeldet und iCloud aktiviert ist.
  3. Prüfe, ob Cloud-Sync in Progains an ist. Öffne Planer › Zahnrad-Symbol › Einstellungen › iCloud und vergewissere dich, dass der Schalter Cloud-Sync eingeschaltet ist. Der Schalter erscheint nur, solange dein Premium-Abo aktiv ist.
  4. Prüfe, ob dein Premium-Abo aktiv ist. Ist es abgelaufen, zeigt der Bereich Status Premium erforderlich an. Siehe Abo verwalten oder kündigen.
  5. Prüfe deinen iCloud-Account und deinen Speicher. Öffne Einstellungen › [dein Name] › iCloud und vergewissere dich, dass mit dem Account alles in Ordnung ist und dein iCloud-Speicher nicht voll ist.
  6. Beende Progains, öffne es neu und gib ihm etwas Zeit. Schließe die App vollständig und öffne sie wieder, und lass sie dann ein bis zwei Minuten bei guter Verbindung geöffnet. Die Synchronisierung läuft im Hintergrund und ist nicht immer sofort fertig.
  7. Klappt es immer noch nicht? Der Bereich Status zeigt bei Nur lokal und Sync-Fehler eine Zeile mit technischen Details, und im Fehlerzustand gibt es einen Button Fehlerdetails kopieren. Kopiere diesen Text und schick ihn an den Support – er sagt uns genau, was schiefgelaufen ist.

Deine Daten sind in beiden Fällen sicher. Progains schreibt deine Workouts immer zuerst auf das Gerät. Ein Sync-Problem betrifft nur, ob Änderungen deine anderen Geräte erreichen – nicht, ob dein Training aufgezeichnet wird.

Der Tab Fortschritt und die gesperrte Verlaufskarte unten im Tab Verlauf führen zum selben Bildschirm.

Progains について

Progains は、iPhone 向けの筋力トレーニング・ワークアウト記録アプリです。ウェイトトレーニングに取り組む方が、プラン、トレーニング、進捗をひとつの場所にまとめておけるように作られています。

  • プログラム — フェーズ、トレーニング日、休養日で構成された複数週のプランを、スケジュール上に展開します
  • テンプレート — いつでも開始できる、繰り返し使える単発のワークアウト
  • エクササイズライブラリ — 編集できる初期収録のエクササイズに加え、メモ・フォームのポイント・写真を付けた自分だけのエクササイズも追加できます
  • ワークアウトの記録 — 全セットのレップ数・重量・RPE を記録。ウォームアップ、本番セット、ドロップセットに対応し、休憩タイマーも自動で動きます
  • 履歴 — 完了したワークアウトはすべて保存され、検索やカレンダーからの閲覧ができます
  • 進捗 — 推定 1RM の推移をグラフで表示（プレミアム限定）
  • クラウド同期 — ご自身の iCloud を通じて、すべてのデバイスでトレーニングを共有（プレミアム限定）

ワークアウトの記録は、常にオフラインでも行えます。 Progains はトレーニング内容をその場でデバイスに保存します。インターネット接続が必要なのは、サブスクリプションを購入するときと、クラウド同期をオンにしているプレミアム会員が iCloud に同期するときだけです。

プログラム

プログラムとは、Progains がスケジュール上に展開し、日ごとに実行していく繰り返し型のトレーニングプランです。プランナータブのプログラムから作成します。

プログラムを作成する

  1. プログラムに名前を付けます。必要に応じてメモも入力できます。
  2. 期間を選びます。終了日のあるプランなら週数を固定、ずっと繰り返すプランなら無期限を選びます。
  3. 必要であればフェーズを追加します。フェーズとは、独自の名前と週数を持つ複数週のブロックです — 筋肥大、筋力、ピーキングのように、プランを段階に分けたいときに便利です。シンプルにしたい場合は、フェーズを分けずにプログラム全体を 1 つのブロックとして実行することもできます。
  4. フェーズの中に、繰り返す日を追加します。各日にはラベルと、その日のエクササイズのリスト、そして目標とするセット数とレップ数を設定します。
  5. どの日でも休養日に設定できます。休養日もパターンの一部なので、「3 日オン・1 日オフ」の週は、4 日目を休養日にした 4 日構成として作ります。

プログラムを実行する

プログラムをアクティブに設定すると、Progains がそれを基にスケジュールを作成します。スタートタブにはその日に予定されたワークアウトが表示され、カレンダーには今後の予定が表示されます。アクティブにできるプログラムは、同時に 1 つだけです。

トレーニングをしばらく離れる必要があるときは、アクティブなプログラムを一時停止できます。あとから、中断した位置のまま再開できます。どのプログラムがアクティブか、そして一時停止中かどうかは、クラウド同期がオンのときデバイス間で同期されます。

無料アカウントで保持できるプログラムは2 個までです。プレミアムではこの上限がなくなります。上限を超えたプログラムが削除されることはありません — いずれかを削除するかアップグレードするまで、新しいプログラムを追加できなくなるだけです。

テンプレート

テンプレートとは、繰り返し使える単発のワークアウトです — スケジュールも週の設定もなく、繰り返すセッションそのものだけがあります。その日の調子に合わせてトレーニングしたいけれど、いつものメニューはすぐ始められるようにしておきたい、というときに便利です。

作成はプランナータブのテンプレートから行います。ワークアウトに名前を付け、エクササイズを追加して、予定するセット数とレップ数を設定します。

テンプレートからワークアウトを開始する

  1. スタートタブを開きます。
  2. 画面上部のセレクタをプログラムからテンプレートに切り替えます。
  3. 保存済みテンプレートから 1 つ選ぶと、そのエクササイズが読み込まれた状態でセッションが開きます。

同じ画面には空のワークアウトを開始もあります。何も入っていない状態でセッションを始められるので、進めながらエクササイズを追加できます。事前に計画しておく必要はありません。

無料アカウントで保持できるテンプレートは3 個までです。プレミアムではこの上限がなくなります。

エクササイズライブラリ

エクササイズタブがライブラリです。Progains には部位と器具で分類された初期収録のエクササイズが用意されており、自分のエクササイズを追加することもできます。

エクササイズに含まれる情報

  • 名前
  • 部位 — 胸、背中、肩、前腕、上腕二頭筋、上腕三頭筋、脚、腹筋、全身、有酸素
  • 器具 — バーベル、ダンベル、マシン、ケーブル、自重、ケトルベル、バンド
  • メモ — 覚えておきたいことを自由に書けます
  • 説明 — ご自身で書いたフォームのポイント
  • 写真（任意） — セッティングの様子、マシン、プレートの組み合わせなど

部位から探すことも、名前で検索することもできます。エクササイズをタップすると編集でき、Progains があらかじめ用意したものも編集の対象です — 名前を変更したり、自分なりのポイントを書き加えたり、通っているジムに合わせて器具を変更したりできます。

使わない収録済みエクササイズは削除できます。削除したことは記憶されるため、クラウド同期がオンでも、ほかのデバイスで再び表示されることはありません。

写真の追加には iOS 標準の写真ピッカーを使用します。選んだ 1 枚の画像だけがアプリに渡されます。Progains が写真ライブラリにアクセスすることはありません。

ワークアウトを記録する

ワークアウトはスタートタブから開始します — アクティブなプログラムで予定されている日のメニューでも、自由に組むセッションでもかまいません。開始したあとは、セッションが終わるまでロガーが表示され続けます。

セットを記録する

各セットではレップ数と重量を記録し、必要に応じてRPE（自覚的運動強度）とメモも入力できます。丸印をタップすると、そのセットが完了になります。

セットには 3 つの種類があり、エクササイズ内でそれぞれ分けて表示されます。

  • ウォームアップセット — 本番の前に、必要な数だけ追加できます
  • 本番セット — ボリュームと推定 1RM の計算対象になるセット
  • ドロップセット — 本番セットと、それに続く重量を下げたセットをまとめて記録します

前回の記録

各セットの行には、そのエクササイズの前回の記録が表示されます。超えたい数値が、入力中の数値のすぐ隣に常にある状態です。

休憩タイマー

休憩タイマーは自動で始まります。タイマーは 2 種類あり、それぞれ役割が異なります。

  • セット間の休憩 — 現在のエクササイズにまだセットが残っている間に動作します
  • エクササイズ間の休憩 — 次のエクササイズが控えている場合に、そのエクササイズの最終セットのあとで動作します。ワークアウトの最後のセットのあとには動作しません

既定値はプランナー › 歯車アイコン › 設定で設定します。セット間の休憩は、エクササイズごとに個別に変更できます。動作中のタイマーは、スキップしたり時間を変更したりできます。

アプリを離れた場合は、Progains が通知を予約するので、休憩が終わったことがわかります。アプリを開いたままの場合は、画面上にアラートが表示されます。

一時停止と中断

ワークアウトは一時停止でき、停止していた時間は記録される所要時間に含まれません。セッションを下にスワイプすると、タブバーの上にストップウォッチ付きのバーとして表示されたまま進行します — タップすればセッションに戻れます。

ワークアウトの記録と履歴

ワークアウトを終了すると、すべてのセット、総ボリューム、所要時間、メモ、そしてセッションのきつさが保存されます。破棄されるものはありません。

記録したワークアウトは記録タブで確認できます。月ごとにまとめて表示することも、カレンダーから閲覧することもできます。ワークアウト名やエクササイズ名で検索も可能です。ワークアウトをタップすると詳細が表示され、入力を間違えていた場合は編集できます — 完了したワークアウトを編集しても、記録された所要時間が変わることはありません。

さかのぼれる期間

無料: 直近3 か月のワークアウト。
プレミアム: これまでに記録したすべてのワークアウト。

ここは正確にお伝えしておきます。無料アカウントでも、3 か月より前のワークアウトが削除されることはありません。デバイスにはそのままの形で保存されており、サブスクリプションに登録した時点ですぐに再び表示されます。サブスクリプションが失効した場合も、表示される範囲が再び狭まるだけです — 失われるものはありません。

プレミアム

Progains は、最も大切な部分を無料で使えます。プログラムとテンプレートの作成、そして無制限のワークアウト記録です。プレミアムは任意のサブスクリプションで、次の機能が追加されます。

  • クラウド同期 — ワークアウト、プログラム、テンプレート、エクササイズを、ご自身のプライベートな iCloud アカウントを通じてデバイス間で同期します
  • すべてのワークアウト履歴 — 直近 3 か月だけでなく、これまでに記録したすべてのワークアウトを閲覧・検索できます
  • 進捗の分析 — すべてのエクササイズについて、推定 1RM の推移をグラフで表示します
  • 長期統計 — 伸びのペース、停滞の検出、4 週・8 週・12 週の筋力予測
  • プログラム無制限 — 無料版の上限 2 個を超えて作成できます
  • テンプレート無制限 — 無料版の上限 3 個を超えて作成できます

プレミアムは自動更新のサブスクリプションで、月額プランと年額プランがあります。価格は App Store の地域ごとに設定されているため、お客様の通貨での正確な金額はアプリ内のプレミアム画面に表示されます。解約しない限り自動的に更新されます。

プレミアムが終了しても、データが削除されることはありません。進捗グラフと古い履歴は表示できなくなり、クラウド同期は新しい変更の反映を停止しますが、すべてのワークアウトはデバイスに残り、再び登録すれば元どおり表示されます。

クラウド同期

クラウド同期はプレミアム機能です。Apple アカウントにサインインしている Apple デバイス間で、ワークアウト、プログラム、テンプレート、エクササイズ、設定を同じ状態に保ちます。

仕組み

  • ワークアウトのデータは、まずお使いのデバイスに保存されます。クラウド同期のオン・オフにかかわらず、実際に使われるのは常にこのローカルのデータです。
  • プレミアム会員の方は、Progains の プランナー › 歯車アイコン › 設定 › iCloud › クラウド同期 でクラウド同期をオンにできます。変更はすぐに反映され、再起動は不要です。
  • オンにすると、Progains は Apple の iCloud と CloudKit の仕組みを利用して、ご自身の iCloud アカウント内の プライベートデータベース にデータをミラーリングします。
  • お客様ご自身のプライベートデータベースであるため、データは Apple アカウントに紐づくご自身のデバイスの間だけを移動します。Progains の開発者がその内容を読むことはできず、アクセス権もありません。
  • クラウド同期には、有効な iCloud アカウントで iCloud にサインインした iPhone が必要です。サインインしていない場合、Progains はその旨を表示し、データをローカルに保存し続けます。
  • クラウド同期をオフにしても、何かが削除されることはありません。ミラーリングが止まるだけで、ローカルのデータはそのまま残ります。

同期ステータスを確認する

プランナー › 歯車アイコン › 設定 を開きます。クラウド同期がオンのときは ステータス セクションが表示され、現在の状態（同期中…、同期済み、iCloud にサインインしていません、同期エラー、ローカルのみ）に加えて、このデバイス の行と、最後に同期に成功した時刻が確認できます。

「ローカルのみ」のステータス

設定 › ステータス では、このデバイス の行に iCloud 有効 または ローカルのみ のいずれかが表示されます。

ローカルのみ は、文字どおりの意味です。ワークアウトのデータはこの iPhone に安全に保存されていますが、このデバイスで iCloud へのミラーリングが開始されなかったため、最近の変更が iCloud にコピーされていません。データが失われたわけではなく、ローカルには無傷で残っています。

これは、ローカルのデータベースを同期に対応した形式へ移行する必要がある場合や、デバイスで iCloud の設定が完了していない場合に起こることがあります。

トラブルシューティングの手順

  1. インターネット接続を確認します。デバイスで Wi-Fi またはモバイルデータ通信が使えることを確認してください。
  2. iCloud にサインインしているか確認します。iPhone で 設定 › [あなたの名前] を開き、サインインしていることと、iCloud が有効になっていることを確認してください。
  3. Progains でクラウド同期がオンになっているか確認します。プランナー › 歯車アイコン › 設定 › iCloud を開き、クラウド同期 のスイッチがオンになっていることを確認してください。このスイッチは、プレミアムのサブスクリプションが有効な間のみ表示されます。
  4. プレミアムのサブスクリプションが有効か確認します。失効している場合、ステータスのセクションに プレミアムが必要です と表示されます。サブスクリプションの管理・解約 をご覧ください。
  5. iCloud アカウントと保存容量を確認します。設定 › [あなたの名前] › iCloud を開き、アカウントに問題がないことと、iCloud の保存容量が不足していないことを確認してください。
  6. Progains を終了して開き直し、しばらく待ちます。アプリを完全に終了してから開き直し、通信状態のよい場所で 1〜2 分ほど開いたままにしてください。同期はバックグラウンドで実行されるため、必ずしもすぐに終わるとは限りません。
  7. それでも解決しない場合は ステータスのセクションには、ローカルのみ と 同期エラー の状態のときに技術的な詳細を示す行が表示され、エラーの状態には エラーの詳細をコピー ボタンがあります。そのテキストをコピーして サポートまでお送りください。何が起きたのかを正確に把握できます。

どちらの場合でも、データは安全です。Progains は常に、まずデバイスにワークアウトを書き込みます。同期の問題が影響するのは、変更が他のデバイスに届くかどうかであって、トレーニングが記録されるかどうかではありません。

購入を復元する

すでに Progains プレミアムに登録済みの場合 — たとえば別のデバイスで登録した場合や、アプリを再インストールする前に登録していた場合 — 再度お支払いすることなくサブスクリプションを復元できます。

  1. iPhone で Progains を開きます。
  2. プレミアム画面を開きます。アプリ内のプレミアムの案内からいつでも開けますが、いちばん早いのは プランナー タブを開き、左上の 歯車アイコン から 設定 を開いて、iCloud セクションの プレミアムを解除 をタップする方法です。進捗 タブや、記録 タブの下部にあるロックされた履歴カードからも同じ画面が開きます。
  3. Progains プレミアム の画面で、（登録ボタンの下にある）購入を復元 をタップします。
  4. App Store がアカウントを確認するまで少しお待ちください。サブスクリプションが見つかると、プレミアム機能はすぐに使えるようになります。再起動は不要です。

最初にサブスクリプションを購入した Apple アカウントでデバイスにサインインしているか確認してください。復元では Apple から購入履歴を読み取るため、別の Apple アカウントでは見つかりません。サインイン中のアカウントは、iPhone の 設定 › [あなたの名前] › メディアと購入 で確認できます。

プレミアム画面にすでに 「プレミアム会員です」 と表示されている場合、サブスクリプションは有効なので、復元は必要ありません。

サブスクリプションの購入は、すべて App Store を通じて Apple が処理します。Progains がお客様の支払い情報を見たり処理したりすることは一切ありません。アプリが受け取るのは、サブスクリプションが現在有効かどうかという情報だけです。

解約するとデータはどうなりますか？

解約してもワークアウトのデータは消去されません。記録した内容はすべてそのままデバイスに保存され、引き続き Progains でエクササイズの作成、ワークアウトの実施、トレーニングの記録を行えます。

変わるのはプレミアム機能へのアクセスです。サブスクリプションが失効すると、Progains は新しい変更を iCloud にミラーリングしなくなり、ワークアウト履歴の一覧は直近 3 か月分に戻ります。それより古いワークアウトが削除されることはありません。データはデバイスに残っており、再度登録すると再び表示されます。

返金は Progains ではなく Apple が対応します。お申し込みは reportaproblem.apple.com から行えます。

ワークアウトデータの保存方法

Progains は、ワークアウトの情報 — エクササイズ、プログラム、テンプレート、予定した日、ワークアウト、そして記録したすべてのセット、レップ、重量、RPE — を、お使いの iPhone 内にある、アプリ専用のローカルデータベースに保存します。

プレミアム会員の方がクラウド同期をオンにすると、同じデータが ご自身の iCloud アカウント内のプライベート CloudKit データベース にもミラーリングされます。これにより、他の Apple デバイスでもデータが表示されます。

Progains は、ワークアウトデータのために独自のサーバーを運用していません。作成する Progains アカウントはなく、ログインもなく、トレーニング内容がアップロードされる Progains のバックエンドもありません。データはお使いのデバイスか、ご自身の iCloud のいずれかにあり、開発者が運用するサーバーに置かれることも、第三者に送信されることもありません。

何がどこに保存されるかの詳細については、Progains プライバシーポリシー をご覧ください。

Acerca de Progains

Progains es una app de entrenamiento de fuerza y registro de entrenamientos para iPhone. Está hecha para quienes entrenan con pesas y quieren tener su plan, sus sesiones y su progreso en un mismo lugar.

  • Programas — planes de varias semanas con fases, días de entrenamiento y días de descanso, organizados en un calendario
  • Plantillas — entrenamientos sueltos y reutilizables que puedes empezar cuando quieras
  • Biblioteca de ejercicios — un conjunto inicial que puedes editar, más tus propios ejercicios con notas, indicaciones y fotos
  • Registro de entrenamientos — repeticiones, peso y RPE en cada serie, con series de calentamiento, efectivas y descendentes, y temporizadores de descanso automáticos
  • Historial — cada entrenamiento terminado se guarda, y puedes buscarlo o consultarlo en un calendario
  • Progreso — tu 1RM estimado en gráficas a lo largo del tiempo, con Premium
  • Sincronización en la nube — tu entrenamiento en todos tus dispositivos a través de tu propio iCloud, con Premium

Registrar entrenamientos siempre funciona sin conexión. Progains guarda tu entrenamiento en el dispositivo sobre la marcha. Solo necesitas conexión a internet para comprar una suscripción y, si tienes Premium con la Sincronización en la nube activada, para sincronizar con iCloud.

Programas

Un programa es un plan de entrenamiento que se repite y que Progains organiza en un calendario para que lo sigas día a día. Crea el tuyo en la pestaña Planificador, en Programas.

Crear un programa

  1. Ponle un nombre al programa y añade notas si quieres.
  2. Elige cuánto dura: Semanas fijas para un plan con fecha de fin, o Indefinido para uno que se repite sin parar.
  3. Añade fases si las quieres. Una fase es un bloque de varias semanas con su propio nombre y número de semanas — útil para dividir el plan en etapas, como hipertrofia, luego fuerza y luego un pico. Si prefieres algo más simple, un programa también puede funcionar como un único bloque.
  4. Dentro de una fase, añade los días que se repiten. Cada día tiene una etiqueta y su propia lista de ejercicios, con las series y repeticiones que te propones hacer.
  5. Marca cualquier día como día de descanso. Los días de descanso forman parte del patrón: una semana de 3 días de entrenamiento y 1 de descanso son simplemente cuatro días, con el cuarto marcado como descanso.

Seguir un programa

Marca un programa como activo y Progains creará tu calendario a partir de él. La pestaña Inicio te muestra entonces el entrenamiento que toca, y el calendario, los días que vienen. Solo hay un programa activo a la vez.

Puedes pausar un programa activo si necesitas dejar de entrenar un tiempo, y retomarlo después sin perder tu sitio. Qué programa está activo, y si está en pausa, se sincroniza entre tus dispositivos cuando la Sincronización en la nube está activada.

Las cuentas gratuitas pueden tener 2 programas. Premium elimina el límite. Los programas que superen el límite nunca se borran — simplemente no puedes añadir nuevos hasta que elimines uno o pases a Premium.

Plantillas

Una plantilla es un entrenamiento suelto y reutilizable — sin calendario ni semanas, solo una sesión que repites. Usa plantillas cuando entrenas según te apetece pero quieres tener la misma sesión lista y preparada.

Créalas en la pestaña Planificador, en Plantillas: ponle nombre al entrenamiento, añade ejercicios y define las series y repeticiones que piensas hacer.

Empezar un entrenamiento desde una plantilla

  1. Abre la pestaña Inicio.
  2. Cambia el selector de arriba de Programa a Plantilla.
  3. Elige una de tus plantillas guardadas y la sesión se abrirá con esos ejercicios ya cargados.

En esa misma pantalla tienes Empezar entrenamiento vacío, que abre una sesión sin nada para que añadas ejercicios sobre la marcha. No hace falta planificar nada de antemano.

Las cuentas gratuitas pueden tener 3 plantillas. Premium elimina el límite.

Biblioteca de ejercicios

La pestaña Ejercicios es tu biblioteca. Progains incluye un conjunto inicial organizado por grupo muscular y material, y puedes añadir los tuyos.

Qué contiene un ejercicio

  • Nombre
  • Grupo muscular — pecho, espalda, hombros, antebrazo, bíceps, tríceps, piernas, abdominales, cuerpo completo o cardio
  • Material — barra, mancuerna, máquina, polea, peso corporal, pesa rusa o banda
  • Notas — cualquier cosa que quieras recordar sobre él
  • Instrucciones — tus propias indicaciones de técnica, escritas por ti
  • Una foto opcional — la posición de partida, una máquina, cómo colocas los discos

Explora por grupo muscular o busca por nombre. Toca cualquier ejercicio para editarlo, incluidos los que trae Progains — cámbiales el nombre, añade tus propias indicaciones o cambia el material para que coincida con tu gimnasio.

Puedes eliminar los ejercicios incluidos que no uses. Esa eliminación se recuerda, así que el ejercicio no reaparecerá en tus otros dispositivos cuando la Sincronización en la nube está activada.

Al añadir una foto se usa el selector de fotos estándar de iOS: eliges una imagen y solo esa imagen se le entrega a la app. Progains nunca accede a tu fototeca.

Registrar un entrenamiento

Empieza un entrenamiento desde la pestaña Inicio — puede ser el día que tenga programado tu programa activo o una sesión libre. A partir de ahí, el registro te acompaña durante toda la sesión.

Registrar series

En cada serie anotas repeticiones, peso y, si quieres, el RPE (esfuerzo percibido) junto con una nota. Toca el círculo para marcar una serie como completada.

Hay tres tipos de series, y cada tipo se agrupa por separado dentro del ejercicio:

  • Series de calentamiento — añade tantas como necesites antes del trabajo de verdad
  • Series efectivas — las que cuentan para tu volumen y tu 1RM estimado
  • Series descendentes — una serie efectiva seguida de sus bajadas de peso, registradas juntas

Lo que hiciste la última vez

Cada fila de serie muestra tu marca anterior en ese ejercicio, así que el número que quieres superar siempre está al lado del que estás anotando.

Temporizadores de descanso

Los temporizadores de descanso se inician solos. Hay dos, y cada uno hace algo distinto:

  • Entre series — corre mientras queden series del ejercicio actual
  • Entre ejercicios — corre tras la última serie de un ejercicio cuando aún queda otro ejercicio por hacer, y nunca después de la última serie del entrenamiento

Define los valores por defecto en Planificador › icono del engranaje › Ajustes, y cambia el descanso entre series en ejercicios concretos. Puedes saltarte o editar un temporizador mientras está en marcha.

Si sales de la app, Progains programa una notificación para que sepas igualmente cuándo termina el descanso. Si te quedas en la app, verás un aviso en pantalla.

Pausar y salir un momento

Puedes pausar un entrenamiento, y el tiempo en pausa no cuenta en la duración registrada. Si deslizas la sesión hacia abajo, sigue en marcha como una barra encima de la barra de pestañas, con un cronómetro en vivo — tócala para volver.

Registros e historial de entrenamientos

Al terminar un entrenamiento se guarda: cada serie, el volumen total, la duración, tus notas y lo dura que te resultó la sesión. No se descarta nada.

Encuentra tus entrenamientos en la pestaña Registros, agrupados por mes o vistos en un calendario. Busca por nombre de entrenamiento o de ejercicio. Toca cualquier entrenamiento para verlo completo y edítalo si anotaste algo mal — editar un entrenamiento terminado nunca cambia su duración registrada.

Cuánto historial puedes ver

Gratis: los entrenamientos de los últimos 3 meses.
Premium: todos los entrenamientos que has registrado.

Esto es lo que conviene dejar claro: en una cuenta gratuita, los entrenamientos de más de tres meses no se borran. Se quedan guardados en tu dispositivo tal cual estaban, y reaparecen en cuanto te suscribes. Si la suscripción caduca, la lista simplemente se vuelve a acortar — no se pierde nada.

Premium

Progains es gratis en la parte que más importa: crear programas y plantillas, y registrar entrenamientos sin límite. Premium es una suscripción opcional que añade lo siguiente.

  • Sincronización en la nube — mantén entrenamientos, programas, plantillas y ejercicios sincronizados entre tus dispositivos a través de tu propia cuenta privada de iCloud
  • Historial completo de entrenamientos — consulta y busca todos los entrenamientos que has registrado, no solo los de los últimos tres meses
  • Análisis de progreso — tu 1RM estimado en gráficas a lo largo del tiempo para cada ejercicio
  • Estadísticas a largo plazo — velocidad de la tendencia, detección de estancamientos y proyecciones de fuerza a 4, 8 y 12 semanas
  • Programas ilimitados — más allá del límite gratuito de 2
  • Plantillas ilimitadas — más allá del límite gratuito de 3

Premium es una suscripción de renovación automática, con plan mensual o anual. El precio exacto en tu moneda aparece en la pantalla Premium de la app, ya que se fija según la región del App Store. Se renueva automáticamente hasta que la canceles.

Perder Premium nunca elimina tus datos. Las gráficas de progreso y el historial más antiguo dejan de poder verse, y la Sincronización en la nube deja de replicar los cambios nuevos, pero todos los entrenamientos siguen en tu dispositivo y vuelven si te suscribes de nuevo.

Sincronización en la nube

La Sincronización en la nube es una función Premium. Mantiene coherentes tus entrenamientos, programas, plantillas, ejercicios y ajustes en todos los dispositivos Apple que tengan la sesión iniciada con tu cuenta de Apple.

Cómo funciona

  • Tus datos de entrenamiento se guardan primero en tu dispositivo. Esa copia local es siempre la que estás usando, tanto si la Sincronización en la nube está activada como si no.
  • Los suscriptores Premium pueden activar la Sincronización en la nube en Progains desde Planificador › icono del engranaje › Ajustes › iCloud › Sincronización en la nube. El cambio se aplica de inmediato: no hace falta reiniciar.
  • Cuando está activada, Progains usa la infraestructura de iCloud y CloudKit de Apple para replicar tus datos en la base de datos privada de tu propia cuenta de iCloud.
  • Como es tu base de datos privada, los datos viajan entre tus propios dispositivos bajo tu cuenta de Apple. El desarrollador de Progains no puede leerlos ni tiene acceso a ellos.
  • La Sincronización en la nube requiere un iPhone con la sesión iniciada en iCloud y una cuenta de iCloud operativa. Si no has iniciado sesión, Progains te lo indicará y seguirá guardando tus datos localmente.
  • Desactivar la Sincronización en la nube no borra nada. Simplemente deja de replicar; tus datos locales se quedan exactamente donde están.

Consultar el estado de la sincronización

Abre Planificador › icono del engranaje › Ajustes. Cuando la Sincronización en la nube está activada, aparece una sección Estado que muestra la situación actual —Sincronizando…, Sincronizado, No has iniciado sesión en iCloud, Error de sincronización o Solo local—, junto con una fila Este dispositivo y la hora de la última sincronización correcta.

Estado "Solo local"

En Ajustes › Estado, la fila Este dispositivo muestra iCloud activo o Solo local.

Solo local significa exactamente lo que dice: tus datos de entrenamiento están guardados de forma segura en este iPhone, pero la réplica en iCloud no llegó a iniciarse en este dispositivo, así que los cambios recientes no se han copiado a iCloud. No se ha perdido nada: los datos están intactos en local.

Esto puede ocurrir si la base de datos local necesita migrar a un formato compatible con la sincronización, o si iCloud no está del todo configurado en el dispositivo.

Pasos para solucionarlo

  1. Comprueba tu conexión a internet. Confirma que el Wi-Fi o los datos móviles funcionan en el dispositivo.
  2. Comprueba que has iniciado sesión en iCloud. Abre Ajustes › [tu nombre] en tu iPhone y asegúrate de que has iniciado sesión y de que iCloud está activado.
  3. Comprueba que la Sincronización en la nube está activada en Progains. Abre Planificador › icono del engranaje › Ajustes › iCloud y confirma que el interruptor de Sincronización en la nube está activado. El interruptor solo aparece mientras tu suscripción Premium está activa.
  4. Comprueba que tu suscripción Premium está activa. Si ha caducado, la sección Estado dirá Se requiere Premium. Consulta Gestionar o cancelar una suscripción.
  5. Comprueba tu cuenta y tu almacenamiento de iCloud. Abre Ajustes › [tu nombre] › iCloud y confirma que la cuenta funciona correctamente y que no te has quedado sin almacenamiento de iCloud.
  6. Cierra Progains, vuelve a abrirla y dale tiempo. Cierra la app por completo y ábrela de nuevo; después déjala abierta un minuto o dos con buena conexión. La sincronización se ejecuta en segundo plano y no siempre es instantánea.
  7. ¿Sigues atascado? La sección Estado muestra una línea con detalles técnicos bajo los estados Solo local y Error de sincronización, y el estado de error incluye un botón Copiar detalles del error. Copia ese texto y envíaselo a soporte: nos dice exactamente qué ha fallado.

Tus datos están a salvo en cualquier caso. Progains siempre escribe tus entrenamientos primero en el dispositivo. Un problema de sincronización afecta a si los cambios llegan a tus otros dispositivos, no a si tu entrenamiento queda registrado.

Restaurar compras

Si ya te has suscrito a Progains Premium —por ejemplo en otro dispositivo, o antes de reinstalar la app— puedes restaurar tu suscripción sin volver a pagar.

  1. Abre Progains en tu iPhone.
  2. Abre la pantalla de Premium. Puedes llegar a ella desde cualquier aviso de Premium de la app; la ruta más rápida es la pestaña Planificador, luego el icono del engranaje de la esquina superior izquierda para abrir Ajustes y después Desbloquear Premium en la sección iCloud. La pestaña Progreso y la tarjeta de historial bloqueada del final de la pestaña Registros abren esa misma pantalla.
  3. En la pantalla Progains Premium, toca Restaurar compras (debajo del botón de suscripción).
  4. Espera un momento mientras el App Store comprueba tu cuenta. En cuanto encuentre tu suscripción, las funciones Premium se desbloquean al instante: no hace falta reiniciar nada.

Asegúrate de que el dispositivo tenga la sesión iniciada con la cuenta de Apple que compró la suscripción originalmente. Al restaurar se consulta tu historial de compras en Apple, así que con otra cuenta de Apple no aparecerá. Puedes ver qué cuenta tiene la sesión iniciada en Ajustes › [tu nombre] › Contenido y compras en tu iPhone.

Si la pantalla de Premium ya dice "Eres Premium", tu suscripción está activa y no hay nada que restaurar.

Las compras de suscripciones las gestiona íntegramente Apple a través del App Store. Progains nunca ve ni procesa tu información de pago: la app solo recibe si tu suscripción está activa en este momento.

À propos de Progains

Progains est une app de musculation et de suivi d'entraînement pour iPhone. Elle est conçue pour celles et ceux qui s'entraînent avec des charges et veulent leur plan, leurs séances et leur progression au même endroit.

  • Programmes — des plans de plusieurs semaines avec des phases, des jours d'entraînement et des jours de repos, répartis sur un calendrier
  • Modèles — des séances uniques et réutilisables que vous pouvez lancer à tout moment
  • Bibliothèque d'exercices — une base de départ modifiable, plus vos propres exercices avec notes, consignes et photos
  • Suivi des séances — répétitions, charge et RPE pour chaque série, avec séries d'échauffement, séries effectives et dropsets, et minuteurs de repos automatiques
  • Historique — chaque séance terminée est enregistrée, avec recherche et consultation sur un calendrier
  • Progression — votre 1RM estimé suivi dans le temps sous forme de graphique, avec Premium
  • Synchronisation iCloud — vos entraînements sur tous vos appareils via votre propre iCloud, avec Premium

L'enregistrement des séances fonctionne toujours hors ligne. Progains enregistre vos entraînements sur votre appareil au fur et à mesure. Une connexion Internet n'est nécessaire que pour acheter un abonnement et, si vous êtes abonné Premium avec la Synchronisation iCloud activée, pour synchroniser avec iCloud.

Programmes

Un programme est un plan d'entraînement récurrent que Progains répartit sur un calendrier pour que vous le suiviez jour après jour. Créez le vôtre dans l'onglet Planificateur, sous Programmes.

Créer un programme

  1. Donnez un nom à votre programme, et des notes si vous le souhaitez.
  2. Choisissez sa durée : Nombre de semaines fixe pour un plan avec une date de fin, ou Illimité pour un plan qui se répète indéfiniment.
  3. Ajoutez des phases si vous en voulez. Une phase est un bloc de plusieurs semaines avec son propre nom et son nombre de semaines — pratique pour découper un plan en étapes : hypertrophie, puis force, puis pic de forme. Si vous préférez rester simple, un programme peut aussi se dérouler en un seul bloc.
  4. Dans une phase, ajoutez les jours qui se répètent. Chaque jour porte un libellé et possède sa propre liste d'exercices, avec les séries et les répétitions que vous visez.
  5. Marquez n'importe quel jour comme jour de repos. Les jours de repos font partie du schéma : une semaine en 3 jours d'entraînement puis 1 de repos, ce sont simplement quatre jours dont le quatrième est marqué comme repos.

Suivre un programme

Définissez un programme comme actif et Progains en construit votre calendrier. L'onglet Démarrer affiche alors la séance prévue, et le calendrier montre les jours à venir. Un seul programme est actif à la fois.

Vous pouvez mettre un programme actif en pause si vous devez faire une coupure, puis le reprendre plus tard sans perdre votre place. Le programme actif et son état de pause se synchronisent entre vos appareils lorsque la Synchronisation iCloud est activée.

Les comptes gratuits peuvent conserver 2 programmes. Premium supprime cette limite. Les programmes au-delà de la limite ne sont jamais supprimés — vous ne pouvez simplement plus en ajouter tant que vous n'en supprimez pas un ou que vous ne passez pas à Premium.

Modèles

Un modèle est une séance unique et réutilisable — pas de calendrier, pas de semaines, juste une séance que vous répétez. Les modèles sont parfaits si vous vous entraînez au feeling tout en voulant retrouver la même séance prête à l'emploi.

Créez-les dans l'onglet Planificateur, sous Modèles : nommez la séance, ajoutez des exercices, puis indiquez les séries et les répétitions prévues.

Lancer une séance à partir d'un modèle

  1. Ouvrez l'onglet Démarrer.
  2. Basculez le sélecteur en haut de Programme vers Modèle.
  3. Choisissez un de vos modèles enregistrés : la séance s'ouvre avec ces exercices déjà chargés.

Le même écran propose Commencer une séance vide, qui démarre une séance sans rien dedans pour que vous ajoutiez les exercices au fur et à mesure. Rien n'a besoin d'être prévu à l'avance.

Les comptes gratuits peuvent conserver 3 modèles. Premium supprime cette limite.

Bibliothèque d'exercices

L'onglet Exercices est votre bibliothèque. Progains est livré avec une base de départ organisée par groupe musculaire et par matériel, et vous pouvez y ajouter les vôtres.

Ce que contient un exercice

  • Nom
  • Groupe musculaire — pectoraux, dos, épaules, avant-bras, biceps, triceps, jambes, abdominaux, corps entier ou cardio
  • Matériel — barre, haltère, machine, poulie, poids du corps, kettlebell ou élastique
  • Notes — tout ce dont vous voulez vous souvenir à son sujet
  • Instructions — vos propres consignes d'exécution, rédigées par vous
  • Une photo, en option — une mise en place, une machine, un chargement de disques

Parcourez la liste par groupe musculaire ou cherchez par nom. Touchez un exercice pour le modifier, y compris ceux fournis par Progains — renommez-les, ajoutez vos propres consignes ou changez le matériel pour correspondre à votre salle.

Vous pouvez supprimer les exercices intégrés que vous n'utilisez pas. Cette suppression est mémorisée : l'exercice ne réapparaîtra pas sur vos autres appareils lorsque la Synchronisation iCloud est activée.

L'ajout d'une photo passe par le sélecteur de photos standard d'iOS : vous choisissez une image et seule cette image est transmise à l'app. Progains n'a jamais accès à votre photothèque.

Enregistrer une séance

Lancez une séance depuis l'onglet Démarrer — soit le jour prévu par votre programme actif, soit une séance libre. Le suivi vous accompagne ensuite pendant toute la séance.

Enregistrer vos séries

Pour chaque série, vous notez les répétitions, la charge et, si vous le souhaitez, le RPE (évaluation de l'effort perçu) ainsi qu'une note. Touchez le cercle pour marquer une série comme terminée.

Il existe trois types de séries, regroupées séparément dans l'exercice :

  • Séries d'échauffement — ajoutez-en autant que nécessaire avant le vrai travail
  • Séries effectives — celles qui comptent dans votre volume et votre 1RM estimé
  • Dropsets — une série effective suivie de ses dégressions, enregistrées ensemble

Ce que vous avez fait la dernière fois

Chaque ligne de série affiche votre performance précédente sur cet exercice : le chiffre à battre est toujours à côté de celui que vous saisissez.

Minuteurs de repos

Les minuteurs de repos se déclenchent tout seuls. Il y en a deux, et ils ne font pas le même travail :

  • Entre les séries — il tourne tant qu'il reste des séries sur l'exercice en cours
  • Entre les exercices — il tourne après la dernière série d'un exercice lorsqu'un autre exercice reste à faire, et jamais après la dernière série de la séance

Définissez les valeurs par défaut dans Planificateur › icône d'engrenage › Réglages, et remplacez le repos entre séries exercice par exercice. Un minuteur peut être passé ou modifié pendant qu'il tourne.

Si vous quittez l'app, Progains programme une notification pour que vous sachiez quand même que le repos est terminé. Si vous restez dans l'app, vous recevez plutôt une alerte à l'écran.

Mettre en pause et s'absenter

Vous pouvez mettre une séance en pause : le temps en pause est exclu de la durée enregistrée. En balayant la séance vers le bas, elle continue de tourner sous forme de barre au-dessus de la barre d'onglets, avec un chronomètre en direct — touchez-la pour y revenir.

Journal et historique des séances

Terminer une séance l'enregistre : chaque série, le volume total, la durée, vos notes et la difficulté ressentie. Rien n'est mis de côté.

Retrouvez vos séances dans l'onglet Journal, regroupées par mois ou consultées sur un calendrier. Cherchez par nom de séance ou d'exercice. Touchez une séance pour la voir en entier, et modifiez-la si vous avez noté quelque chose de travers — modifier une séance terminée ne change jamais sa durée enregistrée.

Jusqu'où vous pouvez remonter

Gratuit : les séances des 3 derniers mois.
Premium : toutes les séances que vous avez enregistrées depuis le début.

C'est le point sur lequel il faut être précis : sur un compte gratuit, les séances de plus de trois mois ne sont pas supprimées. Elles restent enregistrées sur votre appareil telles quelles, et réapparaissent dès que vous vous abonnez. Si un abonnement prend fin, la liste se resserre simplement à nouveau — rien n'est perdu.

Premium

Progains est gratuit pour l'essentiel : créer des programmes et des modèles, et enregistrer un nombre illimité de séances. Premium est un abonnement facultatif qui ajoute ce qui suit.

  • Synchronisation iCloud — gardez séances, programmes, modèles et exercices synchronisés entre vos appareils via votre propre compte iCloud privé
  • Historique complet des séances — consultez et recherchez toutes les séances que vous avez enregistrées, pas seulement les trois derniers mois
  • Analyses de progression — votre 1RM estimé suivi dans le temps sous forme de graphique, pour chaque exercice
  • Statistiques à long terme — vitesse de progression, détection des plateaux et projections de force à 4, 8 et 12 semaines
  • Programmes illimités — au-delà de la limite gratuite de 2
  • Modèles illimités — au-delà de la limite gratuite de 3

Premium est un abonnement à renouvellement automatique, proposé au mois ou à l'année. Le prix exact dans votre devise est affiché sur l'écran Premium de l'app, car il est fixé par région de l'App Store. Il se renouvelle automatiquement jusqu'à ce que vous l'annuliez.

Perdre Premium ne supprime jamais vos données. Les graphiques de progression et l'historique ancien deviennent inaccessibles, et la Synchronisation iCloud cesse de répercuter les nouvelles modifications, mais chaque séance reste sur votre appareil et revient si vous vous réabonnez.

Synchronisation iCloud

La Synchronisation iCloud est une fonctionnalité Premium. Elle maintient vos séances, vos programmes, vos modèles, vos exercices et vos réglages cohérents entre les appareils Apple connectés à votre compte Apple.

Comment ça fonctionne

  • Vos données d'entraînement sont d'abord stockées sur votre appareil. Cette copie locale est toujours celle que vous utilisez, que la Synchronisation iCloud soit activée ou non.
  • Les abonnés Premium peuvent activer la Synchronisation iCloud dans Progains sous Planificateur › icône d'engrenage › Réglages › iCloud › Synchronisation iCloud. Le changement prend effet immédiatement — aucun redémarrage n'est nécessaire.
  • Lorsqu'elle est activée, Progains utilise l'infrastructure iCloud et CloudKit d'Apple pour répliquer vos données dans la base de données privée de votre propre compte iCloud.
  • Comme il s'agit de votre base de données privée, les données circulent entre vos propres appareils, sous votre compte Apple. Le développeur de Progains ne peut pas les lire et n'y a aucun accès.
  • La Synchronisation iCloud nécessite un iPhone connecté à iCloud avec un compte iCloud fonctionnel. Si vous n'êtes pas connecté, Progains vous le signale et continue d'enregistrer vos données localement.
  • Désactiver la Synchronisation iCloud ne supprime rien. La réplication s'arrête ; vos données locales restent exactement là où elles sont.

Vérifier votre statut de synchronisation

Ouvrez Planificateur › icône d'engrenage › Réglages. Lorsque la Synchronisation iCloud est activée, une section Statut apparaît et affiche l'état actuel — Synchronisation…, Synchronisé, Non connecté à iCloud, Erreur de synchronisation ou Local uniquement — ainsi qu'une ligne Cet appareil et l'heure de la dernière synchronisation réussie.

Statut « Local uniquement »

Dans Réglages › Statut, la ligne Cet appareil affiche soit iCloud actif, soit Local uniquement.

Local uniquement signifie exactement ce qui est écrit : vos données d'entraînement sont enregistrées en toute sécurité sur cet iPhone, mais la réplication vers iCloud n'a pas démarré sur cet appareil, si bien que les modifications récentes n'ont pas été copiées vers iCloud. Rien n'a été perdu — les données sont intactes en local.

Cela peut arriver si la base de données locale doit être migrée vers un format compatible avec la synchronisation, ou si iCloud n'est pas entièrement configuré sur l'appareil.

Étapes de dépannage

  1. Vérifiez votre connexion Internet. Assurez-vous que le Wi-Fi ou les données cellulaires fonctionnent sur l'appareil.
  2. Vérifiez que vous êtes connecté à iCloud. Ouvrez Réglages › [votre nom] sur votre iPhone et assurez-vous que vous êtes connecté et qu'iCloud est activé.
  3. Vérifiez que la Synchronisation iCloud est activée dans Progains. Ouvrez Planificateur › icône d'engrenage › Réglages › iCloud et vérifiez que l'option Synchronisation iCloud est activée. Cette option n'apparaît que tant que votre abonnement Premium est actif.
  4. Vérifiez que votre abonnement Premium est actif. S'il a pris fin, la section Statut indiquera Premium requis. Voir Gérer ou résilier un abonnement.
  5. Vérifiez votre compte et votre stockage iCloud. Ouvrez Réglages › [votre nom] › iCloud et vérifiez que le compte fonctionne correctement et que vous n'avez pas épuisé votre stockage iCloud.
  6. Quittez et rouvrez Progains, puis laissez-lui le temps. Fermez complètement l'app et rouvrez-la, puis laissez-la ouverte une ou deux minutes avec une bonne connexion. La synchronisation s'effectue en arrière-plan et n'est pas toujours instantanée.
  7. Toujours bloqué ? La section Statut affiche une ligne de détail technique sous les états Local uniquement et Erreur de synchronisation, et l'état d'erreur comporte un bouton Copier les détails de l'erreur. Copiez ce texte et envoyez-le à l'assistance — il nous indique exactement ce qui n'a pas fonctionné.

Vos données sont en sécurité dans tous les cas. Progains écrit toujours vos séances sur l'appareil en premier. Un problème de synchronisation a une incidence sur la transmission des modifications à vos autres appareils, pas sur l'enregistrement de votre entraînement.

Programas

Um programa é um plano de treino que se repete e que o Progains organiza em um calendário para você seguir dia a dia. Crie o seu na aba Planejador, em Programas.

Como montar um programa

  1. Dê um nome ao programa e, se quiser, adicione notas.
  2. Escolha a duração: Semanas fixas para um plano com data de término, ou Sem prazo para um plano que segue se repetindo.
  3. Adicione fases, se quiser. Uma fase é um bloco de várias semanas com nome e número de semanas próprios — útil para dividir o plano em etapas, como hipertrofia, depois força e depois um pico. Se você prefere manter as coisas simples, o programa também pode rodar como um bloco único.
  4. Dentro de uma fase, adicione os dias que se repetem. Cada dia tem um nome e a sua própria lista de exercícios, com as séries e repetições que você pretende fazer.
  5. Marque qualquer dia como dia de descanso. Os dias de descanso fazem parte do ciclo, então uma semana de três treinos e um descanso é simplesmente quatro dias, com o quarto marcado como descanso.

Como seguir um programa

Defina um programa como ativo e o Progains monta o seu calendário a partir dele. A aba Iniciar passa a mostrar o treino do dia, e o calendário mostra os dias seguintes. Só um programa fica ativo por vez.

Você pode pausar um programa ativo se precisar dar um tempo nos treinos e retomar depois sem perder o ponto em que parou. Qual programa está ativo, e se ele está pausado, sincroniza entre os seus dispositivos quando a Sincronização na nuvem está ativada.

Contas gratuitas podem manter 2 programas. O Premium remove o limite. Programas acima do limite nunca são apagados — você só não consegue criar novos até remover um ou assinar.

Modelos

Um modelo é um treino único e reutilizável — sem calendário, sem semanas, só uma sessão que você repete. Use modelos quando você treina no seu ritmo, mas ainda quer o mesmo treino montado e pronto.

Crie os seus na aba Planejador, em Modelos: dê um nome ao treino, adicione exercícios e defina as séries e repetições que você pretende fazer.

Como iniciar um treino a partir de um modelo

  1. Abra a aba Iniciar.
  2. No seletor do topo, troque de Programa para Modelo.
  3. Escolha um dos seus modelos salvos: a sessão abre com esses exercícios já carregados.

A mesma tela tem Iniciar treino vazio, que começa uma sessão sem nada dentro, para você adicionar exercícios conforme treina. Nada precisa ser planejado com antecedência.

Contas gratuitas podem manter 3 modelos. O Premium remove o limite.

Biblioteca de exercícios

A aba Exercícios é a sua biblioteca. O Progains vem com um conjunto inicial organizado por grupo muscular e equipamento, e você pode adicionar os seus.

O que um exercício guarda

  • Nome
  • Grupo muscular — peito, costas, ombros, antebraço, bíceps, tríceps, pernas, abdômen, corpo inteiro ou cardio
  • Equipamento — barra, halteres, máquina, polia, peso corporal, kettlebell ou elástico
  • Notas — qualquer coisa que você queira lembrar sobre ele
  • Instruções — as suas próprias dicas de execução, escritas por você
  • Uma foto opcional — a posição inicial, uma máquina, a montagem das anilhas

Navegue por grupo muscular ou busque pelo nome. Toque em qualquer exercício para editá-lo, inclusive os que já vêm no Progains — renomeie, adicione as suas dicas ou mude o equipamento para combinar com a sua academia.

Você pode apagar os exercícios nativos que não usa. Essa exclusão fica registrada, então ele não reaparece nos seus outros dispositivos quando a Sincronização na nuvem está ativada.

Para adicionar uma foto, o app usa o seletor de fotos padrão do iOS: você escolhe uma imagem e só ela é entregue ao app. O Progains nunca tem acesso à sua fototeca.

Como registrar um treino

Inicie um treino pela aba Iniciar — pode ser o dia agendado pelo seu programa ativo ou uma sessão livre. A partir daí, o registro acompanha você durante todo o treino.

Registrar séries

Em cada série você registra repetições, carga e, se quiser, o RPE (percepção subjetiva de esforço) mais uma nota. Toque no círculo para marcar a série como concluída.

Há três tipos de série, cada um agrupado separadamente dentro do exercício:

  • Séries de aquecimento — adicione quantas precisar antes do trabalho pra valer
  • Séries válidas — as que contam para o seu volume e para o seu 1RM estimado
  • Drop-sets — uma série válida seguida das suas reduções de carga, registradas juntas

O que você fez da última vez

Cada linha de série mostra o seu desempenho anterior naquele exercício, então o número que você quer superar fica sempre ao lado do número que você está digitando.

Cronômetros de descanso

Os cronômetros de descanso começam sozinhos. São dois, e cada um faz uma coisa:

  • Entre séries — roda enquanto ainda restam séries do exercício atual
  • Entre exercícios — roda depois da última série de um exercício quando ainda há outro exercício pela frente, e nunca depois da última série do treino

Defina os valores padrão em Planejador › ícone de engrenagem › Ajustes, e altere o descanso entre séries em exercícios específicos. Um cronômetro pode ser pulado ou editado enquanto está rodando.

Se você sair do app, o Progains agenda uma notificação para você saber quando o descanso terminar. Se ficar no app, aparece um alerta na tela.

Pausar e sair um momento

Você pode pausar um treino, e o tempo em pausa não entra na duração registrada. Se deslizar a sessão para baixo, ela continua rodando como uma barra acima da barra de abas, com um cronômetro ao vivo — toque nela para voltar.

Registros e histórico de treinos

Ao concluir um treino, tudo fica salvo: cada série, o volume total, a duração, as suas notas e o quanto a sessão foi puxada. Nada é descartado.

Encontre os seus treinos na aba Registros, agrupados por mês ou vistos em um calendário. Busque pelo nome do treino ou do exercício. Toque em qualquer treino para ver tudo e editá-lo se registrou algo errado — editar um treino concluído nunca altera a duração registrada.

Esse é o ponto que vale deixar bem claro: treinos com mais de três meses não são apagados na conta gratuita. Eles ficam salvos no seu dispositivo exatamente como estavam e reaparecem no momento em que você assinar. Se a assinatura expirar, a lista simplesmente encurta de novo — nada se perde.

Sincronização na nuvem

A Sincronização na nuvem é um recurso Premium. Ela mantém os seus treinos, programas, modelos, exercícios e ajustes consistentes entre os dispositivos Apple conectados à sua Conta Apple.

Como funciona

  • Os seus dados de treino são salvos primeiro no dispositivo. Essa cópia local é sempre a que você está usando, com a Sincronização na nuvem ligada ou desligada.
  • Assinantes Premium podem ligar a Sincronização na nuvem no Progains em Planejador › ícone de engrenagem › Ajustes › iCloud › Sincronização na nuvem. A mudança vale na hora — não é preciso reiniciar.
  • Quando ela está ligada, o Progains usa a infraestrutura do iCloud e do CloudKit da Apple para espelhar os seus dados no banco de dados privado da sua própria conta do iCloud.
  • Como é o seu banco de dados privado, os dados circulam entre os seus próprios dispositivos, sob a sua Conta Apple. O desenvolvedor do Progains não consegue lê-los e não tem acesso a eles.
  • A Sincronização na nuvem exige um iPhone conectado ao iCloud, com uma conta do iCloud funcionando. Se você não estiver conectado, o Progains avisa e continua salvando os seus dados localmente.
  • Desligar a Sincronização na nuvem não apaga nada. Ela apenas para de espelhar; os seus dados locais ficam exatamente onde estão.

Como verificar o status da sincronização

Abra Planejador › ícone de engrenagem › Ajustes. Quando a Sincronização na nuvem está ligada, aparece uma seção Status mostrando o estado atual — Sincronizando…, Sincronizado, Você não está conectado ao iCloud, Erro de sincronização ou Apenas local — junto com uma linha Este dispositivo e o horário da última sincronização bem-sucedida.

Status "Apenas local"

Em Ajustes › Status, a linha Este dispositivo mostra iCloud ativo ou Apenas local.

Apenas local quer dizer exatamente isso: os seus dados de treino estão salvos com segurança neste iPhone, mas o espelhamento para o iCloud não começou neste dispositivo, então as alterações recentes não foram copiadas para o iCloud. Nada foi perdido — os dados estão intactos localmente.

Isso pode acontecer se o banco de dados local precisar migrar para um formato compatível com a sincronização, ou se o iCloud não estiver totalmente configurado no dispositivo.

Passos para resolver

  1. Verifique a sua conexão com a internet. Confirme que o Wi-Fi ou os dados móveis estão funcionando no dispositivo.
  2. Verifique se você está conectado ao iCloud. Abra Ajustes › [seu nome] no seu iPhone e confirme que você está conectado e que o iCloud está ativado.
  3. Verifique se a Sincronização na nuvem está ligada no Progains. Abra Planejador › ícone de engrenagem › Ajustes › iCloud e confirme que a chave da Sincronização na nuvem está ligada. A chave só aparece enquanto a sua assinatura Premium está ativa.
  4. Verifique se a sua assinatura Premium está ativa. Se ela expirou, a seção Status vai dizer Premium necessário. Veja Gerenciar ou cancelar uma assinatura.
  5. Verifique a sua conta e o seu armazenamento do iCloud. Abra Ajustes › [seu nome] › iCloud e confirme que a conta está em ordem e que você não ficou sem espaço no iCloud.
  6. Feche e reabra o Progains, e dê um tempo a ele. Feche o app por completo e abra de novo, depois deixe-o aberto por um ou dois minutos com uma boa conexão. A sincronização acontece em segundo plano e nem sempre é instantânea.
  7. Ainda com problema? A seção Status mostra uma linha com detalhes técnicos nos estados Apenas local e Erro de sincronização, e o estado de erro inclui um botão Copiar detalhes do erro. Copie esse texto e envie para o suporte — ele nos diz exatamente o que deu errado.

Os seus dados estão seguros de qualquer forma. O Progains sempre grava os seus treinos no dispositivo primeiro. Um problema de sincronização afeta se as alterações chegam aos seus outros dispositivos, não se o seu treino foi registrado.

Informazioni su Progains

Progains è un'app per iPhone dedicata all'allenamento della forza e al tracciamento degli allenamenti. È pensata per chi si allena con i pesi e vuole avere il piano, le sessioni e i progressi in un unico posto.

  • Programmi — piani di più settimane con fasi, giorni di allenamento e giorni di riposo, distribuiti su un calendario
  • Modelli — singoli allenamenti riutilizzabili che puoi avviare quando vuoi
  • Libreria esercizi — un set di partenza che puoi modificare, più i tuoi esercizi con note, indicazioni e foto
  • Registrazione degli allenamenti — ripetizioni, peso e RPE per ogni serie, con serie di riscaldamento, serie effettive e dropset, e timer di recupero automatici
  • Cronologia — ogni allenamento concluso viene salvato, con ricerca e calendario per sfogliarlo
  • Progressi — il massimale stimato su 1 ripetizione tracciato nel tempo, con Premium
  • Sincronizzazione cloud — i tuoi allenamenti su tutti i tuoi dispositivi tramite il tuo iCloud, con Premium

Registrare gli allenamenti funziona sempre offline. Progains salva l'allenamento sul tuo dispositivo mentre ti alleni. Serve una connessione a internet solo per acquistare un abbonamento e, se sei abbonato Premium con la Sincronizzazione cloud attiva, per sincronizzare con iCloud.

Programmi

Un programma è un piano di allenamento ricorrente che Progains distribuisce su un calendario, così lo segui giorno per giorno. Creane uno nella scheda Pianificatore, in Programmi.

Creare un programma

  1. Dai un nome al programma e, se vuoi, aggiungi delle note.
  2. Scegli quanto dura: Settimane fisse per un piano con una data di fine, oppure Illimitato per uno che continua a ripetersi.
  3. Aggiungi delle fasi, se ti servono. Una fase è un blocco di più settimane con un nome e un numero di settimane propri — utile per dividere il piano in tappe, ad esempio ipertrofia, poi forza, poi picco. Se preferisci restare sul semplice, un programma può funzionare anche come blocco unico.
  4. Dentro una fase, aggiungi i giorni che si ripetono. Ogni giorno ha un'etichetta e la sua lista di esercizi, con le serie e le ripetizioni che vuoi fare.
  5. Segna un giorno qualsiasi come giorno di riposo. I giorni di riposo fanno parte dello schema: una settimana con 3 giorni di allenamento e 1 di pausa è semplicemente di quattro giorni, con il quarto segnato come riposo.

Seguire un programma

Imposta un programma come attivo e Progains costruisce il tuo calendario a partire da quello. La scheda Inizia mostra l'allenamento in programma e il calendario mostra i giorni successivi. È attivo un solo programma alla volta.

Puoi mettere in pausa un programma attivo se devi fermarti per un po', e riprenderlo più avanti senza perdere il punto in cui eri. Quale programma è attivo, e se è in pausa, si sincronizza tra i tuoi dispositivi quando la Sincronizzazione cloud è attiva.

Gli account gratuiti possono avere 2 programmi. Premium toglie il limite. I programmi oltre il limite non vengono mai eliminati — semplicemente non puoi aggiungerne di nuovi finché non ne rimuovi uno o passi a Premium.

Modelli

Un modello è un singolo allenamento riutilizzabile — niente calendario, niente settimane, solo una sessione che ripeti. Usa i modelli quando ti alleni a sensazione ma vuoi comunque trovare la stessa sessione già pronta.

Creali nella scheda Pianificatore, in Modelli: dai un nome all'allenamento, aggiungi gli esercizi e imposta le serie e le ripetizioni che vuoi fare.

Iniziare un allenamento da un modello

  1. Apri la scheda Inizia.
  2. In alto, sposta il selettore da Programma a Modello.
  3. Scegli uno dei tuoi modelli salvati: la sessione si apre con quegli esercizi già caricati.

Nella stessa schermata c'è Inizia allenamento vuoto, che apre una sessione senza nulla dentro, così aggiungi gli esercizi mentre ti alleni. Non serve pianificare niente in anticipo.

Gli account gratuiti possono avere 3 modelli. Premium toglie il limite.

Libreria esercizi

La scheda Esercizi è la tua libreria. Progains include un set di partenza organizzato per gruppo muscolare e attrezzatura, e puoi aggiungere i tuoi.

Cosa contiene un esercizio

  • Nome
  • Gruppo muscolare — petto, schiena, spalle, avambraccio, bicipiti, tricipiti, gambe, addominali, corpo completo o cardio
  • Attrezzatura — bilanciere, manubrio, macchina, cavi, corpo libero, kettlebell o elastico
  • Note — tutto quello che vuoi ricordarti
  • Istruzioni — le tue indicazioni sulla tecnica, scritte da te
  • Una foto facoltativa — la posizione di partenza, una macchina, la disposizione dei dischi

Sfoglia per gruppo muscolare o cerca per nome. Tocca un esercizio per modificarlo, compresi quelli inclusi in Progains — rinominali, aggiungi le tue indicazioni o cambia l'attrezzatura per adattarla alla tua palestra.

Puoi eliminare gli esercizi inclusi che non usi. L'eliminazione viene ricordata, quindi l'esercizio non ricompare sugli altri dispositivi quando la Sincronizzazione cloud è attiva.

Per aggiungere una foto si usa il selettore foto standard di iOS: scegli una sola immagine ed è l'unica che viene passata all'app. Progains non accede mai alla tua libreria foto.

Registrare un allenamento

Inizia un allenamento dalla scheda Inizia — può essere il giorno previsto dal tuo programma attivo oppure una sessione libera. Da lì il registro ti accompagna per tutta la sessione.

Registrare le serie

Per ogni serie annoti ripetizioni, peso e, se vuoi, l'RPE (sforzo percepito) più una nota. Tocca il cerchio per segnare una serie come completata.

Ci sono tre tipi di serie, raggruppati separatamente dentro l'esercizio:

  • Serie di riscaldamento — aggiungine quante te ne servono prima del lavoro vero
  • Serie effettive — quelle che contano per il tuo volume e per il massimale stimato su 1 ripetizione
  • Dropset — una serie effettiva seguita dai suoi cali di peso, registrati insieme

Cosa hai fatto l'ultima volta

Ogni riga di serie mostra la tua prestazione precedente su quell'esercizio, così il numero da battere è sempre accanto a quello che stai inserendo.

Timer di recupero

I timer di recupero partono da soli. Sono due e fanno cose diverse:

  • Riposo tra le serie — scorre finché restano altre serie dell'esercizio in corso
  • Riposo tra gli esercizi — scorre dopo l'ultima serie di un esercizio quando ne resta un altro da fare, e mai dopo l'ultima serie dell'allenamento

Imposta i valori predefiniti in Pianificatore › icona dell'ingranaggio › Impostazioni, e cambia il riposo tra le serie sui singoli esercizi. Un timer si può saltare o modificare mentre scorre.

Se esci dall'app, Progains programma una notifica così sai comunque quando il recupero è finito. Se resti nell'app, ricevi un avviso a schermo.

Mettere in pausa e allontanarsi

Puoi mettere in pausa un allenamento, e il tempo in pausa non viene conteggiato nella durata registrata. Se fai scorrere la sessione verso il basso, resta attiva come barra sopra la barra delle schede, con un cronometro in tempo reale — toccala per tornare.

Registri e cronologia degli allenamenti

Quando concludi un allenamento viene salvato: ogni serie, il volume totale, la durata, le tue note e quanto è stata dura la sessione. Non si butta via niente.

Trovi i tuoi allenamenti nella scheda Registri, raggruppati per mese o da sfogliare su un calendario. Cerca per nome dell'allenamento o dell'esercizio. Tocca un allenamento per vederlo per intero e modificarlo se hai registrato qualcosa di sbagliato — modificare un allenamento concluso non ne cambia mai la durata registrata.

  • Sincronizzazione cloud — tieni allenamenti, programmi, modelli ed esercizi sincronizzati su tutti i tuoi dispositivi tramite il tuo account iCloud privato
  • Cronologia completa degli allenamenti — sfoglia e cerca tutti gli allenamenti che hai registrato, non solo gli ultimi tre mesi
  • Analisi dei progressi — il massimale stimato su 1 ripetizione tracciato nel tempo per ogni esercizio
  • Statistiche a lungo termine — velocità del trend, rilevamento dei plateau e proiezioni di forza a 4, 8 e 12 settimane
  • Programmi illimitati — oltre il limite gratuito di 2
  • Modelli illimitati — oltre il limite gratuito di 3

Premium è un abbonamento con rinnovo automatico, mensile o annuale. Il prezzo esatto nella tua valuta è indicato nella schermata Premium dell'app, perché viene fissato per ogni regione dell'App Store. Si rinnova automaticamente finché non lo disdici.

Perdere Premium non cancella mai i tuoi dati. I grafici dei progressi e la cronologia più vecchia non sono più consultabili e la Sincronizzazione cloud smette di replicare le nuove modifiche, ma ogni allenamento resta sul tuo dispositivo e torna se ti abboni di nuovo.

Sincronizzazione cloud

La Sincronizzazione cloud è una funzione Premium. Mantiene allineati allenamenti, programmi, modelli, esercizi e impostazioni su tutti i dispositivi Apple su cui hai effettuato l'accesso con il tuo Account Apple.

Come funziona

  • I dati dei tuoi allenamenti vengono conservati prima di tutto sul tuo dispositivo. Quella copia locale è sempre quella che stai usando, che la Sincronizzazione cloud sia attiva o disattivata.
  • Gli abbonati Premium possono attivare la Sincronizzazione cloud in Progains da Pianificatore › icona a forma di ingranaggio › Impostazioni › iCloud › Sincronizzazione cloud. La modifica ha effetto immediato: non serve riavviare nulla.
  • Quando è attiva, Progains usa l'infrastruttura iCloud e CloudKit di Apple per replicare i tuoi dati nel database privato del tuo account iCloud.
  • Trattandosi del tuo database privato, i dati si spostano tra i tuoi dispositivi sotto il tuo Account Apple. Lo sviluppatore di Progains non può leggerli e non vi ha alcun accesso.
  • La Sincronizzazione cloud richiede un iPhone con l'accesso a iCloud effettuato e un account iCloud funzionante. Se non hai effettuato l'accesso, Progains te lo segnala e continua a salvare i tuoi dati in locale.
  • Disattivare la Sincronizzazione cloud non elimina nulla. Interrompe la replica; i tuoi dati locali restano esattamente dove sono.

Controllare lo stato della sincronizzazione

Apri Pianificatore › icona a forma di ingranaggio › Impostazioni. Quando la Sincronizzazione cloud è attiva, compare una sezione Stato che mostra la situazione attuale — Sincronizzazione…, Sincronizzato, Non hai effettuato l'accesso a iCloud, Errore di sincronizzazione o Solo locale — insieme a una riga Questo dispositivo e all'ora dell'ultima sincronizzazione riuscita.

Stato "Solo locale"

In Impostazioni › Stato, la riga Questo dispositivo mostra iCloud attivo oppure Solo locale.

Solo locale significa esattamente quello che dice: i dati dei tuoi allenamenti sono salvati al sicuro su questo iPhone, ma la replica su iCloud non è partita su questo dispositivo, quindi le modifiche recenti non sono state copiate su iCloud. Non è andato perso nulla: i dati sono intatti in locale.

Può succedere se il database locale deve essere convertito in un formato compatibile con la sincronizzazione, oppure se iCloud non è configurato completamente sul dispositivo.

Come risolvere

  1. Controlla la connessione a internet. Verifica che il Wi-Fi o la rete dati funzionino sul dispositivo.
  2. Controlla di aver effettuato l'accesso a iCloud. Apri Impostazioni › [il tuo nome] sul tuo iPhone e assicurati di aver effettuato l'accesso e che iCloud sia attivo.
  3. Controlla che la Sincronizzazione cloud sia attiva in Progains. Apri Pianificatore › icona a forma di ingranaggio › Impostazioni › iCloud e verifica che l'interruttore Sincronizzazione cloud sia attivo. L'interruttore compare solo mentre il tuo abbonamento Premium è attivo.
  4. Controlla che il tuo abbonamento Premium sia attivo. Se è scaduto, la sezione Stato mostrerà Premium richiesto. Vedi Gestire o disdire un abbonamento.
  5. Controlla il tuo account iCloud e lo spazio di archiviazione. Apri Impostazioni › [il tuo nome] › iCloud e verifica che l'account funzioni correttamente e di non aver esaurito lo spazio di archiviazione iCloud.
  6. Chiudi e riapri Progains, poi dagli un po' di tempo. Chiudi completamente l'app e riaprila, quindi lasciala aperta un minuto o due con una buona connessione. La sincronizzazione avviene in background e non è sempre immediata.
  7. Ancora bloccato? La sezione Stato mostra una riga con un dettaglio tecnico sotto gli stati Solo locale ed Errore di sincronizzazione, e lo stato di errore include un pulsante Copia i dettagli dell'errore. Copia quel testo e invialo all'assistenza: ci dice esattamente che cosa è andato storto.

I tuoi dati sono al sicuro in ogni caso. Progains scrive sempre prima i tuoi allenamenti sul dispositivo. Un problema di sincronizzazione riguarda il fatto che le modifiche arrivino agli altri tuoi dispositivi, non il fatto che il tuo allenamento venga registrato.

关于 Progains

Progains 是一款面向 iPhone 的力量训练与训练记录 App。它专为进行负重训练的人打造，让训练方案、每次训练和训练进展都集中在一处。

  • 计划 — 多周训练方案，可包含阶段、训练日和休息日，并自动排入日程
  • 模板 — 可重复使用的单次训练，随时都能开始
  • 训练动作库 — 内置一套基础动作供你编辑，你也可以添加自己的动作，并附上备注、要点和照片
  • 训练记录 — 记录每一组的次数、重量和 RPE，支持热身、正式组和递减组，还有自动休息计时器
  • 历史 — 每次完成的训练都会保存下来，可搜索，也可在日历上浏览
  • 进展 — 预估 1RM（单次最大重量）随时间变化的图表，需高级版
  • 云同步 — 通过你自己的 iCloud，在你的所有设备上查看训练数据，需高级版

记录训练始终支持离线使用。Progains 会随时把训练数据保存到你的设备上。只有在购买订阅时，以及当你是开启了云同步的高级版订阅用户、需要同步到 iCloud 时，才需要联网。

计划

计划是一套会重复进行的训练方案，Progains 会把它排入日程，让你逐日执行。在计划标签页中，进入计划即可创建。

创建计划

  1. 为计划起一个名称，并可选择添加备注。
  2. 选择它持续多久：需要有结束日期就选固定周数，想一直重复下去就选不限时长。
  3. 如果需要，可以添加阶段。阶段是一个有自己名称和周数的多周区块 — 适合把方案拆分成增肌、力量、冲峰这样的不同时期。如果你想简单一些，整个计划也可以作为单个区块来执行。
  4. 在阶段中添加会重复的训练日。每一天都有自己的名称，以及自己的动作列表和你打算完成的组数与次数。
  5. 任意一天都可以标记为休息日。休息日也是循环的一部分，所以「练三休一」的一周，就是四天中把第四天标记为休息日。

执行计划

把某个计划设为进行中，Progains 就会据此生成你的日程。开始标签页随即会显示当天该做的训练，日历则会显示接下来的安排。同一时间只能有一个计划处于进行中。

如果需要暂时中断训练，可以暂停正在进行的计划，之后再从原来的位置继续，不会丢失进度。哪个计划正在进行、它是否已暂停，都会在开启云同步后在你的各台设备之间同步。

免费账户最多可保留 2 个计划。高级版取消这一上限。超出上限的计划永远不会被删除 — 只是在你删除其中一个或升级之前，无法再添加新的计划。

模板

模板是可以重复使用的单次训练 — 没有日程，没有周数，只是一次你会反复进行的训练。如果你习惯凭状态安排训练，又希望每次都有现成的同一套内容，模板正合适。

在计划标签页的模板中创建：为训练命名，添加动作，再设定你打算完成的组数和次数。

从模板开始一次训练

  1. 打开开始标签页。
  2. 把顶部的选择器从计划切换到模板。
  3. 选择一个已保存的模板，训练随即打开，其中的动作也已经准备就绪。

同一界面上还有开始空白训练，它会开启一次内容为空的训练，你可以边练边添加动作。什么都不必提前计划。

免费账户最多可保留 3 个模板。高级版取消这一上限。

训练动作库

训练动作标签页就是你的动作库。Progains 内置了一套按肌群和器材分类的基础动作，你也可以添加自己的动作。

一个动作包含什么

  • 名称
  • 肌群 — 胸部、背部、肩部、前臂、肱二头肌、肱三头肌、腿部、腹部、全身或有氧
  • 器材 — 杠铃、哑铃、器械、绳索、自重、壶铃或弹力带
  • 备注 — 任何你想记住的内容
  • 说明 — 你自己写下的动作要点
  • 一张可选的照片 — 器械的调节位置、某台机器，或配重片的组合

你可以按肌群浏览，或按名称搜索。点按任意动作即可编辑，包括 Progains 自带的动作 — 你可以重命名、加上自己的要点，或修改器材以匹配你所在的健身房。

用不到的内置动作可以删除。这个删除会被记住，因此在开启云同步后，它不会在你的其他设备上重新出现。

添加照片使用的是标准的 iOS 照片选择器：你选定一张图片，也只有这张图片会交给 App。Progains 绝不会获得访问你照片图库的权限。

记录训练

从开始标签页开始一次训练 — 可以是正在进行的计划为当天安排的训练，也可以是临时自由安排的一次训练。之后，记录界面会在整次训练中一直陪着你。

记录每一组

每一组都可以记录次数和重量，还可以选填 RPE（自觉用力程度）和备注。点按圆圈即可把一组标记为完成。

组分为三种，在动作中分别归类显示：

  • 热身组 — 正式训练之前想加几组就加几组
  • 正式组 — 计入训练容量和预估 1RM 的组
  • 递减组 — 一个正式组加上随后逐次降重的部分，一起记录

上次做到多少

每一组所在的行都会显示你上次做这个动作的成绩，你想要超越的数字，始终就在你正在输入的数字旁边。

休息计时器

休息计时器会自动开始。一共有两个，各司其职：

  • 组间休息 — 当前动作还有剩余组数时运行
  • 动作间休息 — 在某个动作的最后一组结束、且后面还有其他动作时运行；整次训练的最后一组之后绝不会运行

你可以在计划 › 齿轮图标 › 设置中设定默认时长，也可以为单个动作单独覆盖组间休息。计时器在运行时可以跳过或修改。

如果你离开 App，Progains 会安排一条通知，让你依然知道休息何时结束。如果你留在 App 中，则会在屏幕上看到提醒。

暂停与中途离开

你可以暂停训练，暂停的时间不会计入记录的时长。把训练界面向下轻扫，它会变成标签栏上方的一个横条继续运行，并显示实时秒表 — 点按即可返回。

训练记录与历史

完成一次训练，它就会被保存下来：每一组、总训练容量、时长、你的备注，以及这次训练的主观强度。什么都不会被丢弃。

在记录标签页中查看你的训练，可按月份分组，也可以在日历上浏览。你可以按训练或动作名称搜索。点按任意一次训练即可查看完整内容，如果记录有误也可以编辑 — 编辑已完成的训练不会改变它记录的时长。

可以回看多久以前

免费版：最近 3 个月的训练。
高级版：你记录过的每一次训练。

有一点值得说清楚：在免费账户上，超过三个月的训练不会被删除。它们原封不动地保存在你的设备上，只要你订阅就会立刻重新出现。如果订阅到期，列表只是重新收窄 — 没有任何内容会丢失。

高级版

Progains 最重要的那部分可以免费使用：创建计划和模板，以及无限量地记录训练。高级版是可选的订阅，会额外提供以下功能。

  • 云同步 — 通过你自己的私人 iCloud 账户，让训练、计划、模板和动作在你的各台设备之间保持同步
  • 完整训练历史 — 浏览和搜索你记录过的每一次训练，而不只是最近三个月
  • 进展分析 — 每个动作的预估 1RM 随时间变化的图表
  • 长期统计 — 趋势变化速度、平台期检测，以及 4 周、8 周和 12 周的力量预测
  • 无限个计划 — 不再受免费版 2 个的上限
  • 无限个模板 — 不再受免费版 3 个的上限

高级版是自动续期订阅，提供按月和按年两种方式。你所用货币下的具体价格会显示在 App 内的高级版页面上，因为价格是按 App Store 所在地区分别设定的。订阅会自动续期，直到你取消为止。

失去高级版并不会删除你的数据。进展图表和更早的历史记录将无法查看，云同步也会停止同步新的更改，但每一次训练都仍保存在你的设备上，只要再次订阅就会回来。

云同步

云同步是高级版功能。它可以让你的训练、训练方案、模板、训练动作和设置，在登录你 Apple 账户的各台 Apple 设备之间保持一致。

工作原理

  • 你的训练数据首先存储在设备上。无论云同步是开启还是关闭，你正在使用的始终是这份本地副本。
  • 高级版订阅用户可以在 Progains 中开启云同步，路径为 计划 › 齿轮图标 › 设置 › iCloud › 云同步。更改会立即生效 —— 无需重新启动。
  • 开启后，Progains 会使用 Apple 的 iCloud 和 CloudKit 基础服务，把你的数据镜像到你自己 iCloud 账户中的私有数据库。
  • 由于这是你的私有数据库，数据只在你自己 Apple 账户下的设备之间流转。Progains 的开发者无法读取这些数据，也无权访问。
  • 云同步需要 iPhone 已登录 iCloud，并拥有可正常使用的 iCloud 账户。如果你未登录，Progains 会告知你，并继续把你的数据保存在本地。
  • 关闭云同步不会删除任何内容。它只是停止镜像；你的本地数据会原封不动地留在原处。

查看你的同步状态

打开 计划 › 齿轮图标 › 设置。云同步开启时，会出现状态部分，显示当前状态 —— 正在同步…、已同步、未登录 iCloud、同步出错 或 仅本地 —— 并附有本设备一行以及上次成功同步的时间。

「仅本地」状态

在设置 › 状态中，本设备一行会显示 iCloud 已启用 或 仅本地。

仅本地的含义正如字面所示：你的训练数据已安全保存在这台 iPhone 上，但 iCloud 镜像未能在此设备上启动，因此最近的更改尚未复制到 iCloud。没有任何内容丢失 —— 本地数据完好无损。

出现这种情况，可能是因为本地数据库需要迁移到兼容同步的格式，也可能是因为设备上的 iCloud 尚未完全设置好。

排查步骤

  1. 检查你的网络连接。确认设备上的 Wi-Fi 或蜂窝移动数据可以正常使用。
  2. 确认你已登录 iCloud。在 iPhone 上打开 设置 ›[你的姓名]，确认你已登录并且 iCloud 已启用。
  3. 确认 Progains 中的云同步已开启。打开 计划 › 齿轮图标 › 设置 › iCloud，确认云同步开关已打开。该开关仅在你的高级版订阅有效期间才会出现。
  4. 确认你的高级版订阅仍然有效。如果订阅已失效，状态部分会显示需要高级版。请参阅管理或取消订阅。
  5. 检查你的 iCloud 账户和储存空间。打开 设置 ›[你的姓名]› iCloud，确认账户状态正常，并且你的 iCloud 储存空间没有用尽。
  6. 退出并重新打开 Progains，然后给它一点时间。彻底关闭应用再重新打开，在网络良好的情况下让它保持打开一两分钟。同步在后台运行，并不总是立即完成。
  7. 仍然没有解决？在仅本地和同步出错状态下，状态部分会显示一行技术细节，出错状态还会提供复制错误详情按钮。请复制那段文字并发送给支持团队 —— 它能准确告诉我们出了什么问题。

无论哪种情况，你的数据都是安全的。Progains 始终先把你的训练写入设备。同步问题影响的是更改能否传到你的其他设备，而不是你的训练有没有被记录下来。

Progains 소개

Progains는 iPhone용 근력 운동 기록 앱입니다. 웨이트 트레이닝을 하면서 계획과 운동 기록, 성장 과정을 한곳에서 관리하고 싶은 분들을 위해 만들었습니다.

  • 프로그램 — 단계와 운동일, 휴식일로 구성한 여러 주 단위 계획을 일정에 맞춰 배치합니다
  • 템플릿 — 언제든 바로 시작할 수 있는, 반복해서 쓰는 단일 운동
  • 운동 종목 라이브러리 — 자유롭게 수정할 수 있는 기본 종목과, 메모·포인트·사진을 담은 나만의 종목
  • 운동 기록 — 모든 세트의 횟수와 중량, RPE를 기록하고 웜업·본세트·드롭세트를 구분하며, 휴식 타이머가 자동으로 작동합니다
  • 히스토리 — 완료한 모든 운동이 저장되어 검색하거나 캘린더에서 살펴볼 수 있습니다
  • 진행 — 예상 1RM의 변화를 그래프로 확인합니다(프리미엄)
  • 클라우드 동기화 — 본인의 iCloud를 통해 모든 기기에서 운동 데이터를 확인합니다(프리미엄)

운동 기록은 오프라인에서도 언제나 사용할 수 있습니다. Progains는 운동하는 동안 기록을 기기에 바로 저장합니다. 인터넷 연결은 구독을 구매할 때, 그리고 프리미엄 구독자가 클라우드 동기화를 켜고 iCloud에 동기화할 때만 필요합니다.

프로그램

프로그램은 반복되는 훈련 계획으로, Progains가 이를 일정에 배치해 하루하루 따라갈 수 있게 해 줍니다. 플래너 탭의 프로그램에서 만들 수 있습니다.

프로그램 만들기

  1. 프로그램 이름을 정하고, 필요하면 메모를 덧붙입니다.
  2. 기간을 정합니다. 종료일이 있는 계획이라면 고정 주차를, 계속 반복되는 계획이라면 무기한을 선택하세요.
  3. 원한다면 단계를 추가합니다. 단계는 고유한 이름과 주차 수를 갖는 여러 주 단위 블록으로 — 근비대, 근력, 피킹처럼 계획을 여러 구간으로 나눌 때 유용합니다. 간단하게 가고 싶다면 프로그램을 하나의 블록으로 운영해도 됩니다.
  4. 단계 안에는 반복할 날들을 추가합니다. 각 날에는 이름과 함께, 목표 세트 수와 횟수를 지정한 운동 종목 목록이 들어갑니다.
  5. 어떤 날이든 휴식일로 지정할 수 있습니다. 휴식일도 패턴의 일부이므로, 3일 운동하고 1일 쉬는 주기는 네 개의 날 중 마지막을 휴식으로 표시하면 됩니다.

프로그램 진행하기

프로그램을 활성 상태로 지정하면 Progains가 그에 맞춰 일정을 만듭니다. 그러면 시작 탭에 오늘 해야 할 운동이 표시되고, 캘린더에서 앞으로의 일정을 볼 수 있습니다. 활성 프로그램은 한 번에 하나만 지정할 수 있습니다.

운동을 잠시 쉬어야 한다면 활성 프로그램을 일시 정지했다가, 나중에 진행 위치 그대로 다시 이어갈 수 있습니다. 어떤 프로그램이 활성 상태인지, 일시 정지 중인지는 클라우드 동기화가 켜져 있으면 모든 기기에 동기화됩니다.

무료 계정은 프로그램 2개까지 보관할 수 있고, 프리미엄에서는 개수 제한이 없습니다. 제한을 넘는 프로그램이 삭제되는 일은 없습니다 — 기존 프로그램을 지우거나 업그레이드하기 전까지 새 프로그램을 추가할 수 없을 뿐입니다.

템플릿

템플릿은 반복해서 쓰는 하나의 운동입니다 — 일정도 주차도 없이, 그때그때 반복하는 한 번의 운동이죠. 그날 컨디션에 따라 운동하면서도 늘 같은 구성을 준비해 두고 싶을 때 템플릿을 사용하세요.

플래너 탭의 템플릿에서 만들 수 있습니다. 운동 이름을 정하고 종목을 추가한 다음, 계획한 세트 수와 횟수를 입력하세요.

템플릿으로 운동 시작하기

  1. 시작 탭을 엽니다.
  2. 상단의 선택기를 프로그램에서 템플릿으로 전환합니다.
  3. 저장된 템플릿 중 하나를 고르면, 해당 종목이 모두 담긴 상태로 운동이 열립니다.

같은 화면에는 빈 운동 시작도 있습니다. 아무것도 없는 상태로 시작해 운동하면서 종목을 추가할 수 있으니, 미리 계획해 둘 필요가 없습니다.

무료 계정은 템플릿 3개까지 보관할 수 있고, 프리미엄에서는 개수 제한이 없습니다.

운동 종목 라이브러리

운동 탭이 바로 나만의 라이브러리입니다. Progains에는 운동 부위와 장비별로 정리된 기본 종목이 들어 있으며, 여기에 직접 만든 종목을 추가할 수 있습니다.

운동 종목에 담기는 정보

  • 이름
  • 운동 부위 — 가슴, 등, 어깨, 전완, 이두, 삼두, 하체, 복부, 전신, 유산소
  • 장비 — 바벨, 덤벨, 머신, 케이블, 맨몸, 케틀벨, 밴드
  • 메모 — 기억해 두고 싶은 내용은 무엇이든
  • 설명 — 직접 적어 두는 나만의 자세 포인트
  • 사진(선택 사항) — 세팅 모습, 머신, 원판 구성 등

운동 부위별로 둘러보거나 이름으로 검색해 보세요. 종목을 탭하면 편집할 수 있으며, Progains가 기본으로 제공한 종목도 마찬가지입니다 — 이름을 바꾸고, 나만의 포인트를 적고, 다니는 헬스장에 맞게 장비를 바꿀 수 있습니다.

쓰지 않는 기본 종목은 삭제할 수 있습니다. 삭제했다는 사실이 기억되므로, 클라우드 동기화가 켜져 있어도 다른 기기에서 다시 나타나지 않습니다.

사진을 추가할 때는 iOS 기본 사진 선택기를 사용합니다. 직접 고른 이미지 한 장만 앱에 전달되며, Progains가 사진 보관함에 접근하는 일은 없습니다.

운동 기록하기

운동은 시작 탭에서 시작합니다 — 활성 프로그램에 예정된 날의 운동이든, 자유롭게 구성한 운동이든 상관없습니다. 한번 시작하면 기록 화면이 운동이 끝날 때까지 함께합니다.

세트 기록하기

모든 세트마다 횟수와 중량을 기록하고, 필요하면 RPE(운동자각도)와 메모도 남길 수 있습니다. 원을 탭하면 해당 세트가 완료로 표시됩니다.

세트는 세 가지 종류가 있으며, 각 종목 안에서 종류별로 나뉘어 표시됩니다.

  • 웜업 세트 — 본 운동에 들어가기 전에 필요한 만큼 추가할 수 있습니다
  • 본세트 — 볼륨과 예상 1RM 계산에 반영되는 세트
  • 드롭세트 — 본세트와 뒤이어 중량을 낮춘 세트를 함께 기록합니다

지난번 기록

각 세트 행에는 그 종목의 지난번 기록이 함께 표시됩니다. 넘어서야 할 숫자가 지금 입력하는 숫자 바로 옆에 늘 놓여 있는 셈이죠.

휴식 타이머

휴식 타이머는 자동으로 시작됩니다. 타이머는 두 가지이며, 각각 역할이 다릅니다.

  • 세트 간 휴식 — 현재 종목에 남은 세트가 있을 때 작동합니다
  • 운동 간 휴식 — 다음 종목이 남아 있을 때, 한 종목의 마지막 세트를 마친 뒤에 작동합니다. 그날 운동의 마지막 세트 뒤에는 작동하지 않습니다

기본값은 플래너 › 톱니바퀴 아이콘 › 설정에서 지정하고, 세트 간 휴식은 종목별로 따로 설정할 수 있습니다. 작동 중인 타이머는 건너뛰거나 시간을 수정할 수 있습니다.

앱을 벗어나더라도 Progains가 알림을 예약해 두므로 휴식이 끝나는 시점을 알 수 있습니다. 앱에 머물러 있다면 대신 화면에 알림이 표시됩니다.

Progains는 가장 중요한 부분, 즉 프로그램과 템플릿을 만들고 운동을 무제한으로 기록하는 기능을 무료로 제공합니다. 프리미엄은 여기에 다음 기능을 더해 주는 선택형 구독입니다.

  • 무제한 프로그램 — 무료 제한인 2개를 넘어 자유롭게
  • 무제한 템플릿 — 무료 제한인 3개를 넘어 자유롭게

프리미엄은 월간 또는 연간으로 제공되는 자동 갱신 구독입니다. 가격은 App Store 지역별로 책정되므로, 사용 중인 통화 기준의 정확한 금액은 앱의 프리미엄 화면에서 확인할 수 있습니다. 구독은 취소하기 전까지 자동으로 갱신됩니다.

프리미엄이 해지되어도 데이터가 사라지지는 않습니다. 진행 그래프와 오래된 히스토리를 볼 수 없게 되고 클라우드 동기화가 새로운 변경 사항을 더 이상 반영하지 않을 뿐, 모든 운동 기록은 기기에 그대로 남아 있다가 다시 구독하면 되돌아옵니다.

클라우드 동기화

클라우드 동기화는 프리미엄 기능입니다. Apple 계정에 로그인된 Apple 기기 전체에서 운동 기록, 프로그램, 템플릿, 운동 종목, 설정을 동일하게 유지해 줍니다.

작동 방식

  • 운동 데이터는 먼저 기기에 저장됩니다. 클라우드 동기화를 켜든 끄든, 실제로 사용하는 것은 언제나 이 로컬 사본입니다.
  • 프리미엄 구독자는 Progains의 플래너 › 톱니바퀴 아이콘 › 설정 › iCloud › 클라우드 동기화에서 이 기능을 켤 수 있습니다. 변경 사항은 즉시 적용되며 앱을 다시 시작할 필요가 없습니다.
  • 켜져 있으면 Progains는 Apple의 iCloud 및 CloudKit 인프라를 사용해 데이터를 본인의 iCloud 계정에 있는 개인 데이터베이스에 미러링합니다.
  • 본인의 개인 데이터베이스이므로, 데이터는 사용자의 Apple 계정 아래에서 본인 기기 사이를 오갑니다. Progains 개발자는 이를 읽을 수 없으며 접근 권한도 없습니다.
  • 클라우드 동기화를 사용하려면 iPhone이 정상적으로 작동하는 iCloud 계정으로 iCloud에 로그인되어 있어야 합니다. 로그인되어 있지 않으면 Progains가 이를 알려 주고 데이터는 계속 로컬에 저장합니다.
  • 클라우드 동기화를 꺼도 아무것도 삭제되지 않습니다. 미러링만 중단될 뿐, 로컬 데이터는 있던 그대로 남아 있습니다.

동기화 상태 확인하기

플래너 › 톱니바퀴 아이콘 › 설정을 엽니다. 클라우드 동기화가 켜져 있으면 상태 섹션이 나타나 현재 상태 — 동기화 중…, 동기화됨, iCloud에 로그인되어 있지 않습니다, 동기화 오류, 로컬 전용 — 와 함께 이 기기 행과 마지막으로 성공한 동기화 시각을 보여 줍니다.

"로컬 전용" 상태

설정 › 상태의 이 기기 행에는 iCloud 활성 또는 로컬 전용이 표시됩니다.

로컬 전용은 말 그대로의 의미입니다. 운동 데이터는 이 iPhone에 안전하게 저장되어 있지만, 이 기기에서 iCloud 미러링이 시작되지 않아 최근 변경 사항이 iCloud로 복사되지 않았다는 뜻입니다. 사라진 것은 없으며, 데이터는 로컬에 온전히 남아 있습니다.

이는 로컬 데이터베이스를 동기화 가능한 형식으로 마이그레이션해야 하거나, 기기에서 iCloud가 완전히 설정되지 않은 경우에 발생할 수 있습니다.

문제 해결 단계

  1. 인터넷 연결을 확인하세요. 기기에서 Wi-Fi 또는 셀룰러 데이터가 정상적으로 작동하는지 확인합니다.
  2. iCloud에 로그인되어 있는지 확인하세요. iPhone에서 설정 › [사용자 이름]을 열고, 로그인되어 있고 iCloud가 켜져 있는지 확인합니다.
  3. Progains에서 클라우드 동기화가 켜져 있는지 확인하세요. 플래너 › 톱니바퀴 아이콘 › 설정 › iCloud를 열고 클라우드 동기화 스위치가 켜져 있는지 확인합니다. 이 스위치는 프리미엄 구독이 활성 상태일 때만 나타납니다.
  4. 프리미엄 구독이 활성 상태인지 확인하세요. 구독이 만료되었다면 상태 섹션에 프리미엄 필요라고 표시됩니다. 구독 관리 또는 취소를 참고하세요.
  5. iCloud 계정과 저장 공간을 확인하세요. 설정 › [사용자 이름] › iCloud를 열고 계정에 문제가 없는지, iCloud 저장 공간이 부족하지는 않은지 확인합니다.
  6. Progains를 종료했다가 다시 열고 잠시 기다리세요. 앱을 완전히 닫았다가 다시 연 다음, 연결 상태가 좋은 곳에서 1~2분 정도 열어 둡니다. 동기화는 백그라운드에서 진행되며 항상 즉시 이루어지지는 않습니다.
  7. 그래도 해결되지 않나요? 상태 섹션에는 로컬 전용과 동기화 오류 상태일 때 기술 세부 정보 줄이 표시되고, 오류 상태에는 오류 세부 정보 복사 버튼이 있습니다. 그 텍스트를 복사해 지원팀에 보내 주세요. 무엇이 잘못되었는지 정확히 알 수 있습니다.

어느 경우든 데이터는 안전합니다. Progains는 언제나 운동 내용을 기기에 먼저 기록합니다. 동기화 문제는 변경 사항이 다른 기기에 전달되는지에만 영향을 줄 뿐, 훈련이 기록되는지 여부에는 영향을 주지 않습니다.

  3. Progains 프리미엄 화면에서 구독 버튼 아래에 있는 구매 복원을 누릅니다.
  4. App Store가 계정을 확인하는 동안 잠시 기다립니다. 구독이 확인되면 프리미엄 기능이 즉시 잠금 해제되며, 앱을 다시 시작할 필요는 없습니다.

프리미엄 화면에 이미 "프리미엄 이용 중"이라고 표시되어 있다면 구독이 활성 상태이므로 복원할 것이 없습니다.
